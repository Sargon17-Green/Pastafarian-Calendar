# Delta transportus async

Additur `GET /v1/date-job.js` ut computationes quae limitem circiter 180 secundarum in ambitu browser-isolation excedunt non amplius vitam unius petitionis retinere debeant.

Initium job statim `running` cum identificatore reddit; clientis deinde eundem job per petitiones JavaScript breves interrogat. Cum calculus perficitur, corpus canonicae `/v1/date` sub `result` redditur.

Regula anti-catervae manet: machina semantica unum possessorem habet. Initium alterum dum machina occupata est statim `busy` reddit; non queue fit. Polling, `/v1/health` et `/v1/meta` viae control-plane sunt et longum calculum non exspectant.

Resultatum completum ad polling tantum per tempus breve retinetur. Hoc non est memoization, predictive precomputation aut cache semanticus; optimizationes tales postea separatim tractandae sunt.
