# 第 1 階段：交織 DP 二進位索引鍵設計記錄

此記錄只描述測試用規範參考的內部記憶化表示，不改變規範選擇序列或曆法答案。

對固定月份數 m，狀態 (remaining[1..m], opened, closed) 在全部數值屬於 0..255 時，使用 pack('C*', remaining...,opened,closed) 當作雜湊鍵。
對固定長度的向量，此編碼是一一映射：每個整數恰對應一個位元組，且位置固定。因此在同一計數器內，不會有不同狀態碰撞。
若月份數超過 255，或任何來源長度超過 255 / 不是非負十進位整數，就在該計數器整體改用原本無損的逗號分隔文字鍵。
opened/closed 保留在鍵內，並未依賴它們可由有效狀態推導的性質。

此優化對正式每月 4..123 日與最多 47 個月成立，但 t/16_packed_weaving_cache.t 也測試 255/256/257 轉換邊界。
