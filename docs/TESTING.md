# בדיקות שלב 1

הבדיקות נכתבות ומופעלות ב־Dart בלבד וללא חבילת בדיקות חיצונית.

`bin/stage1_tests.dart` בודק בין היתר:

- קבועי יסוד;
- `SAVE` בגבולות המחייבים;
- מנייני יום סביב יום היסוד;
- מנייני עבודה בשלושה כיוונים;
- האבן השנייה מן snapshot הישן;
- פתיחת תמורות בדרגות 1 ו־720;
- rejection קצר קדימה ואחורה;
- בחירה רחבה בסיסית;
- שלמות 17+47 אינדקסים קנוניים;
- בידוד `MonsterContext` בין שתי הפעלות;
- חסימת מסלול production שטרם הגיע לשלבו.

`tool/generate_stage1_fixtures.dart` יוצר מחדש את `fixtures/stage1_expected.json` מתוך ה־oracle המקומי של אותו קו בלבד.

בסביבת העבודה שבה הוכנה החבילה אין Dart SDK, ולכן לא בוצעה הרצה בפועל. אין להסיק מכך PASS. לפני מעבר לשלב 2 חובה להריץ:

```text
dart run bin/stage1_tests.dart
```
