# INT-02 wide selector ABI — candidate
Project PC-BRANCH-COBOL-SIMPLIFIED-CHINESE. Parent 0254ae2ff84c72d878a3e0b46ae4e5c57fef1be9.
`CALENDAR-WIDE-SELECTOR(N,a1,dir,rank,d,status)`, all by reference.
N and a1 are borrowed valid BIG-INTEGER-SERVICE handles, rank a distinct empty handle; direction signed binary-short (+1/-1), d/status unsigned binary-short. rank is detached and caller-owned on success. Inputs are not freed or altered by this module. Status 22 invalid sign/direction/answer/output, 24 N above M^253, other service statuses propagated. On failure d=0 and empty result remains empty.
N positive, a1 in [1,M], M=2^127-1. d=min positive exponent with M^d>=N. Store X-1 as a handle, accumulate digit contributions in ascending powers, compute L=S-S mod N. If X-1>=L return 1 (forward) or N (backward); otherwise return ((X-1) mod N)+1. This is the exact cyclic suffix shortcut and is not uniform sampling. Only constants 1 and M are initialized from text. Count/rank never serialized. Scratch is scoped; free obsolete power/accumulator/digit/term handles each iteration; detached output is freed if scope exit fails. At most 253 iterations. No changes to legacy CALENDAR-WIDE or previously accepted gates.
Model: node test/int02_wide_selector_literal_model.mjs; independently exercised 9,100 toy cases including 1,720 rejected suffixes. Not Native. Next: strict compile and isolated driver exercising d=1,2,248,253 and overflow, both directions, caller ownership and HEAP-LIVE baseline; then implement one-vector weaving. No acceptance claim.
