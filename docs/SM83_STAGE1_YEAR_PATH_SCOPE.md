## 2. Coordinate contract and correction to prior design

Foundation F = -15055671. The public Native395 year5000 entry uses absolute signed32 c in wPairCalcOffset despite its historical name. ROM map entries are signed32 offsets G_i-F, indices -512..512, ordered strictly increasingly. Convert to absolute G_i for interval comparisons. Sauce WorkCountsFromOffsets32 consumes relative (c-F,t-F); Host ask consumes absolute (c,t), converting internally. Never apply the translation twice. Existing design's statement that year entry c is relative, and its design-only status, are superseded by the reviewed implementation and historical acceptance. The comment in CalendarGateYearMakeMapAbsolute calling absolute day the sauce ABI is misleading; runtime conversion before RunSauce is correct.
Year5000 has open < c <= close; at least six gate intervals and length 252..5778. Search [c-5778,c+5778] inclusive, checked signed32 arithmetic, full coverage including equality at the first/last map entries. Accepted c interval [-15303131,-14789634]; implied map endpoints [-15308909,-14783856]. Old gate_window Host oracle requires an external gate and rejects exact coverage equality, so use the accepted extended test's iterative full-map oracle for equality, not a permissive catch of NotImplementedError. Outside the bounded map is unsupported, not a claim of normative nonexistence.

## 3. Proposed fixed-endpoint selector (within Stage1, scope now documented)

Inputs: absolute signed32 calculation c; previous/next known valid year Y with absolute signed32 endpoints and verified map indices i,j (i<j, j-i>=6, span 252..5778); direction NEXT or PREVIOUS. Validate indices and endpoint correspondence; c must be within supported calculation horizon and all sauce inputs must translate without overflow. Do not require c to be inside Y for subsequent walk steps. Candidate window must be completely covered in requested direction. For NEXT fix b=G_j, require b+5778<=G_512, select k>j with k-j>=6 and 252<=G_k-b<=5778. For PREVIOUS fix b=G_i, require b-5778>=G_-512, select k<i with i-k>=6 and 252<=b-G_k<=5778. Boundary equality accepted. Check arithmetic before use, no partial truncation, reject non-gate or invalid Y. There are at most floor(5778/42)-6+1=132 candidates, and at least one when six subsequent/prior gates are fully covered (each gap <=963). Candidate order is strictly increasing span: NEXT scan increasing indices, PREVIOUS decreasing indices; no tie is possible with fixed endpoint. Hence no radix histogram or candidate array is needed. Count by scanning once; call accepted short-rank kernel with bowl=1 and seal 11 or 12, pair (c-F,b-F). Scan a second time to pick 1-based rank or compute the index from the contiguous range. The Host oracle must independently enumerate absolute candidates and full-sort by (length,open), not mirror the index shortcut. Do not assume NEXT and PREVIOUS are inverses.
Proposed result: absolute open/close (s32 each), map indices (signed16 each), span/count/rank (u16 each), 18 bytes total. This is a proposed separate ABI, NOT the existing Native395 18-byte layout (which includes window count/left/right). Keep Native395 ABI intact. Status 0 success, 2 invalid, 6 idle per existing contract. On invalid/idle/abort do not publish; restore caller pair/answer controls, owner, all 16 lease tags and caller's leased 8192-byte bank. Preserve original bank mapping contract (bank3 caller), no scratch SRAM without explicit lease. Ensure publication only after all checks. Reuse bank0 trampolines and existing scratch where safe, avoid additional ROM0 allocations; require ROM0 >=10 free, WRAM0 >=32 free, measured ROMX bank fit and ROM header. No prediction of link success. Provisional per-case 120000-frame cap to be tested.

## 5. Five-field calendar remains a separate Stage1 dependency

README S–X: structure uses fixed absolute pair (c,open+1) translated for sauce. G = number of gate intervals. Bowl2 seal20 selects cutlet count K from 6..min(17,G); seal21 selects lexicographically ordered positive compositions of G, with a partial sum at the internal gate if c lies exactly on one. Bowl5 seal22 selects ordered distinct cutlet name indices among 17. Bowl3 seal30 selects m from ceil(L/123)..min(47,floor(L/4)); seal31 selects lexicographically ordered bounded month lengths (4..123, sum L). Bowl4 seal32 selects the complete month word with prescribed first and last appearance order; exact prefix completion counting and lexicographic unranking, not contiguous months or uniform random permutations. Bowl5 seal33 selects ordered distinct month names among 47. Compute dayInCutlet from actual cutlet opening gate +1 (one-based), dayInMonth from inclusive prefix frequency of selected month. Final five fields (yearNumber,cutletName,dayInCutlet,monthName,dayInMonth); canonical numeric name indices map to the localized catalog, not an English name fallback. AC.1 all 10 five-field vectors are postconditions only.
Candidate counts for compositions, name permutations and month weaving can exceed 16-bit and even 127-bit SAVE ring; use exact wide selection (N) and prove memory/time bounds before code. The short rank kernel cannot stand in for wide selection. No full-calendar implementation or acceptance is implied by Native395 or the Host year-path oracle.
