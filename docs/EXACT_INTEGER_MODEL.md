# Дәл бүтін сан моделі

Нормативтік есепте floating point қолданылмайды. Қазіргі source екі өте кең Zig integer түрін қолданады: семантикалық жалпы аралық үшін `u65535/i65535`, ал ай тоқымасының memo мәні үшін `u32768`.

Ай тоқымасының барлық мүмкін жолдарының саны барлық шектеулерді алып тастағандағы `47^5778` сөздер санынан үлкен емес. Дәл бүтін шекара үшін `47^10 < 2^56` және `47 < 2^6`. Сондықтан:

```text
47^5778
= (47^10)^577 * 47^8
< 2^(56*577 + 6*8)
= 2^32360
< 2^32768
```

Демек `u32768` ай тоқымасының count мәнін кесусіз сақтайды. Қалған bounded combinatorial counts бұдан да кіші, ал `u65535` оларға қосымша кең қор береді.

Бұл дәлел тек алгоритмнің bounded combinatorial кеңістіктерін жабады. Күн осінің өзі математикалық тұрғыдан шектеусіз. Қазіргі public source day мәнін `i65535` арқылы береді, сондықтан бұл 1-кезеңнің спецификациядағы runtime arbitrary-precision талабын әлі толық орындамайды. Осы себептен `SOURCE_LANGUAGE_CATALOG_FROZEN` және Stage 1 completion белгісі әлі қойылған жоқ.
