## 2. דרישת שלמות וסופיות

אי אפשר לקבל `year5000Ready=true` לפני הוכחה שנמנו **כל** הזוגות המכילים את `c`.

לכל מועמד: `c-5778 <= G_i < c <= G_j <= c+5777`. הגבול הימני נובע מכך ש־`G_i<=c-1` ו־`G_j-G_i<=5778` עבור ימים שלמים. עוצרים רק אחרי הוכחה ששערים מחוץ לחלונות הללו אינם עשויים להשתתף. לכל היותר 138 שערים בכל אחד משני החלונות נדרשים כמועמדי קצה, ועוד שער sentinel להוכחת גבול.
