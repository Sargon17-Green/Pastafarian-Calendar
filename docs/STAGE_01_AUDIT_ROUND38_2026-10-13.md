# 第 38 輪：全年第 5000 年所有 43 個相鄰三月窗口的獨立精確總數

日期：2026-10-13，分支 \`Perl+國語\`。僅 Stage 1，不修改 \`main\`、Stage 2、正式 API 或 \`HANDOFF_*\`。

## 目的

既有第 18 輪只檢查 4 個抽樣的三月份，
第 29–35 輪則對原生年份末段 4 個連續月份窗口深入核對。
這雖為深度檢驗，**未完整覆蓋**年度其他 41 個月份相鄰局部。

現以單一原生完整 SHA-256
\`6d64022344c04935e6423aa6f96b285098d35b9b5ecb4b8c57a4c7149773a134\`
檢查來源年份 45 個月份及總 4,244 日，再依零起始索引
\`0..42\` 提取全部 **43 組三個相鄰月份**，無抽樣遺漏。

每組計算以下三個**精確整數**，三者必須完整相等：

1. \`Pastafari::WeavingMemoOracle\` 以剩餘月長／opened／closed
   的獨立遞迴後綴狀態和末次出現閉式；
2. \`Pastafari::WeavingPolynomial\` 的常駐位置多項式狀態轉移；
3. \`Pastafari::WeavingPolynomialStream\` 的序列化磁碟行演算法。

另檢查真正寫出至少一個磁碟矩陣行、回傳 BigInt 變異不
污染獨立計數結果、遞迴私有狀態實際建立。
逐窗口記錄日數、精確位數、私有狀態數、串流行數、
執行時間；最終須驗證當批窗口數完全等於指定值。

## 安全執行與 CI 合約

新增 \`tools/profile_canonical_all_triples.pl\`，
以 \`[weaving-all-triples]\` opt-in 標記啟動四個分離的 GitHub jobs：
- 起始 0、數量 11，涵蓋 0..10；
- 起始 11、數量 11，涵蓋 11..21；
- 起始 22、數量 11，涵蓋 22..32；
- 起始 33、數量 10，涵蓋 33..42。

每工作各自驗證全部來源年份 SHA，子進程 185 秒／
393,216 KiB RSS，外層 260 秒超時，單檔 16 MiB 上限，
對時間或 RSS 超限誠實標示 BLOCKED，數學偏差標為 FAIL。
四個工作**全部** PASS 才可聲稱全年 43 個局部三月窗口完成。

本輪也擴展第 37 輪的 \`t/56_canonical_embedded_snapshot_integrity.t\`
至第八份嵌入的原生年份月長快照，使本次工具的資料污染
在高成本三月核對前立即被攔截。

邊界：**43 個三月局部總數的相等性**並非 45 月
\`4,244\` 日的整年交織總數、全域精確字典序、或
其他語言實作的同值證明。
