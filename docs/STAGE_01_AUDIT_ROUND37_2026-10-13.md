## 本輪新增的防回歸邊界

\`t/56_canonical_embedded_snapshot_integrity.t\` 在任何大型計數之前
**讀取實際檔案文字**，使用無 \`eval\` 的嚴格逗號整數詞法，
核查目前會內嵌 45 月長的七份測試與 profile 工具：

- 完整快照恰出現一次，每月數字為純十進整數，共 **45** 月；
- 全年合計 **4,244 日**，SHA-256 恰等於由原生年份選擇器確認的常數
  \`6d64022344c04935e6423aa6f96b285098d35b9b5ecb4b8c57a4c7149773a134\`；
- 各工具文字中還保留該獨立固定雜湊，不可偷偷改變合約；
- 四個受控窗口在真正全年快照中的順序、長度和天數均精確比對：
  38..41 => 230 日，39..42 => 240 日，40..43 => 322 日，41..44 => 402 日；
- 固定工具應引用的特定月份下標也被檢查，避免變數名標示與
  實際抽取位置不一致；動態 multi-rank 工具必須使用其偏移參數。

這個快速原始碼完整性測試不是正式算法的權威 Oracle；
它的功能是**在開始重運算前擋下不經意資料替換**。
與既有第 5000 年原生重新選擇／獨立哈希相比是補充，
不能替代重新跑 Sauce 和月份選擇器。
