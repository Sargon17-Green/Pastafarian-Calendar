## Contract
CALENDAR-YEAR-CANDIDATES accepts explicit action RD within epoch ±20000, a complete contiguous strictly increasing gate window of 2..280 entries (gaps 42..963), outer gates bracket action ±5778 and lie within ±6741. Caller supplies genuine gates; routine validates structure, not their normative generation. Inputs distinct from caller-owned output buffers; no dynamic allocation. All scalar fields BINARY-LONG SIGNED except status BINARY-SHORT UNSIGNED. Gate table capacity 280; output table capacity 19600 pairs. Rank 0 requests enumeration only, otherwise 1-based. Status 0 success, 22 invalid input/window (empty output), 23 invalid rank (complete enumeration retained, selection zero). Output table fully reset on every call, input never written. Candidate iff opening < action <= closing, length 252..5778, at least six gate intervals. Order ascending length then opening. No duplicates due to unique gate coordinates. A complete window covers every possible opening and closing; extra gates outside the range do not affect candidate membership.
Bound: at most 280 gates; each candidate crosses action, so at most floor(280^2/4)=19600. Direct RD-index table spans at most 13483 slots. Enumeration visits at most 5527*280=1547560 pairs of length and opening. No unbounded iteration. Valid RD coordinates fit signed 32 bits. Arithmetic validation precedes indexing; input ABI requires signed 32-bit storage.
