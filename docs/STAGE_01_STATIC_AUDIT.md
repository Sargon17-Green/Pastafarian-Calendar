# ಹಂತ 1 ಸ್ಥಿರ ಪರಿಶೀಲನೆ

ಕಾರ್ಯಗತ `unicon`, `icon` ಅಥವಾ `icont` toolchain ಈ ಪರಿಸರದಲ್ಲಿ ಲಭ್ಯವಿಲ್ಲ. ಆದ್ದರಿಂದ ಮೂಲ Unicon ಸಂಕಲನ ಮತ್ತು ಕಾರ್ಯಗತ ಪರೀಕ್ಷೆ ಹೊರತುಪಡಿಸಿ ಹಂತ 1ರ ಉಳಿದ ಪರಿಶೀಲನೆ ಪೂರ್ಣಗೊಂಡಿದೆ.

ಪರಿಶೀಲಿಸಿದ ಅಂಶಗಳು:

- `SourceLanguageCatalog` ನಲ್ಲಿ 17 ಕಟ್ಲೆಟ್ ಮತ್ತು 47 ತಿಂಗಳ ಸ್ಥಿರ entries ಇವೆ.
- ಪ್ರತಿಯೊಂದು entry ಯ ಕ್ರಮವನ್ನು `canonicalIndex` ಮಾತ್ರ ನಿರ್ಧರಿಸುತ್ತದೆ.
- catalog ಮಾನ್ಯತೆ ಆವೃತ್ತಿ, ಹಿಮಗಟ್ಟಿದ ಗುರುತು, index ಮತ್ತು ಕನ್ನಡ ಮೂಲಪಠ್ಯದ ಬದಲಾವಣೆಯನ್ನು ಪತ್ತೆಹಚ್ಚುತ್ತದೆ.
- `src/` ಮತ್ತು `test/` ಒಳಗೆ ಯಾವುದೇ ಬದಲಾಗುವ `global` ಘೋಷಣೆ ಇಲ್ಲ.
- ನಿಯಮಾತ್ಮಕ gate ಸಂಗ್ರಹ ಈಗ ಪ್ರತಿ `OracleCalendarState` ಗೆ ಖಾಸಗಿ.
- oracle stone table ಮತ್ತು ಎಲ್ಲ DP memo tables ಪ್ರತಿ ಆಹ್ವಾನಕ್ಕೆ ಸ್ಥಳೀಯ.
- ಮೂಲ ಅರ್ಥಾತ್ಮಕ ಸ್ಥಿತಿಚಿತ್ರಗಳು ಒಳಸೇರಿದ lists ಮತ್ತು table values ಗೆ ಸ್ವಾಮ್ಯ ಹೊಂದಿದ ಆಳ-ನಕಲುಗಳನ್ನು ಬಳಸುತ್ತವೆ.
- table default value ಮತ್ತು keys ಬದಲಾಗದ scalar ಮೌಲ್ಯಗಳಾಗಿರಬೇಕು; ಬದಲಾಗುವ set members, real values, `co-expression` ಮತ್ತು ಬೆಂಬಲಿಸದ ಬದಲಾಗುವ ರಚನೆಗಳನ್ನು ಮೌನವಾಗಿ ಸ್ವೀಕರಿಸಲಾಗುವುದಿಲ್ಲ.
- ಪರೀಕ್ಷಾ ವಿಫಲತೆ ಎಣಿಕೆ ಈಗ ಜಾಗತಿಕವಲ್ಲ; `TestState` ಪ್ರತಿ ಪರೀಕ್ಷಾ ಚಾಲನೆಗೆ ಸೇರಿದೆ.
- ಪುನರಾವರ್ತಿತ ಕರೆಗಳು, ಮಧ್ಯೆ ಬೇರೆ ಕರೆ ಸೇರಿಸಿದ ಕ್ರಮ, return object ಬದಲಾವಣೆ, ಸಂದರ್ಭ ಪ್ರತ್ಯೇಕತೆ, ವಿಫಲ ಮಾನ್ಯತೆ, ಹಿಂತಿರುಗಿಸುವಿಕೆ ಮತ್ತು ಮರುಪ್ರಯತ್ನಕ್ಕಾಗಿ ಹಂತ 1ರ ಪರೀಕ್ಷೆಗಳು ಸೇರಿವೆ.
- ಬಳಕೆದಾರ-ನಿರ್ಮಿತ generator (`suspend`), `create`, `thread` ಅಥವಾ `spawn` ಬಳಕೆ ಇಲ್ಲ.
- ಮುಂದಿನ ಹಂತಗಳಿಗೆ ಸೇರಿದ historical scar ಸಂಕೇತಗಳು `src/` ಅಥವಾ `test/` ಒಳಗೆ ಇಲ್ಲ.
- `monster_bootstrap.icn` ನಿಯಮಾತ್ಮಕ oracle ಅನ್ನು ಕರೆಯುವುದಿಲ್ಲ.
- ಎಲ್ಲಾ ಕಾರ್ಯಗತ ಯೋಜನಾ ಮೂಲಸಂಕೇತ `.icn` ಕಡತಗಳಲ್ಲಿ ಮಾತ್ರ ಇದೆ.
- `run_stage01.sh` ನಿರ್ಮಾಣ ಮತ್ತು ಪರೀಕ್ಷೆ ಆರಂಭಿಸುವುದಕ್ಕಷ್ಟೇ ಸೀಮಿತವಾಗಿದೆ.
- ಪ್ರತಿಯೊಂದು `.icn` ಕಡತದಲ್ಲಿ procedure/end ಸಂಖ್ಯೆಗಳು ಮತ್ತು `{}` ಜೋಡಿಗಳು ಸಮತೋಲನದಲ್ಲಿವೆ.
- procedure ಒಳಗಿನ assignment targets ಸ್ಪಷ್ಟ parameter ಅಥವಾ `local` declaration ಗೆ ಸೇರಿವೆ.
- ನಿಯಮಾತ್ಮಕ ಲೆಕ್ಕದಲ್ಲಿ real literal ಅಥವಾ floating-point conversion ಸೇರಿಸಲಾಗಿಲ್ಲ.
- Unicon ನ ಅನಿಯತ ಪ್ರಮಾಣದ integer semantics ಮೇಲೆ ಮಾತ್ರ ಅವಲಂಬಿಸಲಾಗಿದೆ; ಹೊರಗಿನ BigInt bridge ಇಲ್ಲ.

`./run_stage01.sh` ನಿಜವಾದ Unicon runtime ನಲ್ಲಿ `PASS` ನೀಡುವವರೆಗೆ `LAST_COMPLETED_STAGE=0` ಆಗಿಯೇ ಉಳಿಯುತ್ತದೆ. ಆದರೆ ಅರ್ಥಾತ್ಮಕ ಸ್ಥಿತಿ ಮಾಲೀಕತ್ವ ಪರಿಶೀಲನೆ ಪೂರ್ಣಗೊಂಡಿರುವುದರಿಂದ `SEMANTIC_STATE_OWNER_VALIDATED=YES` ಆಗಿದೆ.
