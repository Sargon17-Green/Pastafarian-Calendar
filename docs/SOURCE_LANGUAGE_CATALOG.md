# SourceLanguageCatalog — српски

Каталог је замрзнут у Stage 1. Нормативни ред се одређује искључиво по `canonicalIndex`. Српски текст никада не учествује у sort/rank/unrank, cache кључу или избору.

## Правило превода и транскрипције

Речи и изрази са јасним лексичким значењем преведени су на природан српски. Властита имена, називи места и намерно бесмислени звучни низови пренети су српском ћирилицом фонетски, без измишљања новог значења. Цели разломачки изрази преведени су као један назив. Код вишезначних обичних именица изабрано је основно конкретно значење које најдиректније одговара облику у изворној листи; тај избор је сада део замрзнутог Stage 1 каталога.

## Непроменљивост

Сваки запис има стални `canonicalIndex`. Будући locale-ови, ако се појаве, смеју бити само преводи српског изворног низа на presentation слоју. Промена locale-а не сме променити ниједан нормативни ID или резултат осим приказане ниске.
