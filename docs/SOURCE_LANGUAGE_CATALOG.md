# ಕನ್ನಡ ಮೂಲಭಾಷಾ ಪಟ್ಟಿಯ ನಿಯಮ

ಪಟ್ಟಿಯ ಆವೃತ್ತಿ `kn-v1`. ಈ ಹಂತದ ನಂತರ ಸ್ಪಷ್ಟ ನಿರ್ದಿಷ್ಟೀಕರಣ ಬದಲಾವಣೆ ಇಲ್ಲದೆ ಇದನ್ನು ಬದಲಾಯಿಸಬಾರದು.

ಅರ್ಥವಿರುವ ಹೆಸರುಗಳನ್ನು ಕನ್ನಡದಲ್ಲಿ ಅವುಗಳ ಅರ್ಥಕ್ಕೆ ಅನುಗುಣವಾಗಿ ಅನುವಾದಿಸಲಾಗಿದೆ. ಸ್ಥಳನಾಮಗಳು, ವ್ಯಕ್ತಿನಾಮಗಳು ಮತ್ತು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಅರ್ಥವಿಲ್ಲದ ಕಲ್ಪಿತ ಧ್ವನಿಸರಣಿಗಳನ್ನು ಕನ್ನಡ ಲಿಪಿಯಲ್ಲಿ ಧ್ವನಿಗೆ ಸಮೀಪವಾಗಿ ಲಿಪ್ಯಂತರಿಸಲಾಗಿದೆ. ಸಂಯುಕ್ತ ಅರ್ಥವಿರುವ ಹೆಸರುಗಳನ್ನು ಒಂದು ಸಂಪೂರ್ಣ ಹೆಸರಾಗಿ ಉಳಿಸಲಾಗಿದೆ.

ಲಿಪ್ಯಂತರದ ಸ್ಥಿರ ನಿಯಮ ಹೀಗಿದೆ: ಮೂಲ ಉಚ್ಚಾರಣೆಯಲ್ಲಿ ಕೇಳುವ ವ್ಯಂಜನ ಕ್ರಮವನ್ನು ಅದೇ ಕ್ರಮದಲ್ಲಿ ಕನ್ನಡ ಅಕ್ಷರಗಳಿಂದ ಪ್ರತಿನಿಧಿಸಲಾಗುತ್ತದೆ; ಸ್ವರಗಳನ್ನು ಉಚ್ಚಾರಣೆಗೆ ಸಮೀಪದ ಕನ್ನಡ ಸ್ವರಚಿಹ್ನೆಗಳಿಂದ ಬರೆಯಲಾಗುತ್ತದೆ; ಪದಾಂತ್ಯದ ವಿದೇಶಿ ವ್ಯಂಜನವನ್ನು ಕನ್ನಡ ಓದುಗರಿಗೆ ಗುರುತಿಸಬಹುದಾದ ರೂಪದಲ್ಲಿ ಉಳಿಸಲಾಗುತ್ತದೆ. ಈ ನಿಯಮ ಅರ್ಥಾತ್ಮಕ ಕ್ರಮ ನಿರ್ಧಾರಕ್ಕೆ ಎಂದಿಗೂ ಒಳಪಡುವುದಿಲ್ಲ; ಅದು ಪ್ರದರ್ಶನ ಪಠ್ಯ ಆಯ್ಕೆ ಮಾಡಲು ಮಾತ್ರ ಬಳಸಲ್ಪಡುತ್ತದೆ.

ನಿಯಮಾತ್ಮಕ ಕ್ರಮ ಸಂಪೂರ್ಣವಾಗಿ `canonicalIndex` ಮೂಲಕ ಮಾತ್ರ ನಿರ್ಧಾರವಾಗುತ್ತದೆ. ಕನ್ನಡ ಅಕ್ಷರಕ್ರಮ, `Unicode` ಕ್ರಮ, ಪ್ರದರ್ಶನ ಭಾಷೆಯ ಜೋಡಣಾಕ್ರಮ, ಅಕ್ಷರರೂಪ ಪರಿವರ್ತನೆ ಅಥವಾ ಹೆಸರುಗಳ ಪಠ್ಯವು ಕ್ರಮಾಂಕ, ಕ್ರಮಾಂಕದಿಂದ ಮರುರಚನೆ, ಆಯ್ಕೆ, ಅರ್ಥಾತ್ಮಕ ಸಂಗ್ರಹಸ್ಮೃತಿ ಕೀಲಿ ಅಥವಾ ಸಂಯೋಜನಾ ಕುಟುಂಬದ ಕ್ರಮವನ್ನು ಬದಲಾಯಿಸಲು ಅನುಮತಿಸಲ್ಪಟ್ಟಿಲ್ಲ.

ಕಟ್ಲೆಟ್ ಪಟ್ಟಿಯಲ್ಲಿ ಸೂಚ್ಯಂಕ 1ರಿಂದ 17ರವರೆಗೆ ಒಮ್ಮೆ ಮಾತ್ರ ಕಾಣುತ್ತದೆ. ತಿಂಗಳ ಪಟ್ಟಿಯಲ್ಲಿ ಸೂಚ್ಯಂಕ 1ರಿಂದ 47ರವರೆಗೆ ಒಮ್ಮೆ ಮಾತ್ರ ಕಾಣುತ್ತದೆ. ಪ್ರದರ್ಶನ ಪಠ್ಯವನ್ನು ಅಂತಿಮ ಪ್ರದರ್ಶನ ಹಂತದಲ್ಲಷ್ಟೇ ಸೂಚ್ಯಂಕದಿಂದ ಪಡೆಯಲಾಗುತ್ತದೆ.

ಭವಿಷ್ಯದಲ್ಲಿ ಪ್ರದರ್ಶನ ಭಾಷಾ ರೂಪ ಸೇರಿಸಿದರೆ ಕ್ರಮ ಹೀಗಿರಬೇಕು:

```text
canonical semantics -> canonicalIndex -> ಕನ್ನಡ ಮೂಲಪಠ್ಯ -> locale translation
```

ಮೇಲಿನ ಸಾಲು ಯಂತ್ರಾತ್ಮಕ ರೂಪರೇಖೆ. ಪ್ರದರ್ಶನ ಭಾಷೆಯ ಪಠ್ಯದಿಂದ ಅರ್ಥಾತ್ಮಕ ಕ್ರಮಕ್ಕೆ ಹಿಂತಿರುಗುವ ಮಾರ್ಗ ನಿಷಿದ್ಧ.


`buildSourceLanguageCatalog` ಪ್ರತಿಯೊಂದು ಕರೆಯಲ್ಲೂ ಹೊಸ `record`/`list` ರಚನಾ ಜಾಲ ಅನ್ನು ನಿರ್ಮಿಸುತ್ತದೆ. `validateSourceLanguageCatalog` ಆವೃತ್ತಿ, ಹಿಮಗಟ್ಟಿದ ಗುರುತು, `canonicalIndex` ಮತ್ತು ಕನ್ನಡ ಮೂಲಪಠ್ಯವನ್ನು ಸ್ಥಿರ procedures ವಿರುದ್ಧ ಪರಿಶೀಲಿಸುತ್ತದೆ. ಕರೆಯುವ ಭಾಗವು ಒಂದು catalog ನಕಲನ್ನು ಬದಲಿಸಿದರೆ ಆ ನಕಲಿನ ಮಾನ್ಯತೆ ವಿಫಲವಾಗುತ್ತದೆ ಮತ್ತು ಬೇರೆ ಹೊಸ ನಕಲು ಬದಲಾಗುವುದಿಲ್ಲ.
