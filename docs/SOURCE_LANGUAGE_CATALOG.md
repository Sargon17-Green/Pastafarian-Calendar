# 來源語言名稱目錄

目錄版本：`1.0.0-stage1-frozen`

來源語言是繁體中文（國語）。第 1 階段完成後，除非規格明確變更，名稱與轉寫規則都不得修改。

## 翻譯規則

具有一般詞彙意義的名稱按語意翻譯，不做希伯來語音譯。完整分數名稱按一個完整名稱翻譯，例如「九分之四」與「五分之三」。歷史地名採常見中文名稱。沒有字面語意、只作聲音名稱的項目採固定音節轉寫，不額外賦予意義。

本實作把「拉加什、阿卡德、埃里都、烏魯克、尼尼微、巴比倫」視為地名；「帕爾古拉什、卡爾舒馬布」視為無字面語意的造詞，使用固定字序的中文音節轉寫。此決定只影響呈現字串，不影響任何規範索引。

## 規範順序

所有選擇、排名與反排名都只處理固定的 `canonicalIndex`。不得以中文筆畫、拼音、Unicode、locale collation 或任何字串比較改變順序。
