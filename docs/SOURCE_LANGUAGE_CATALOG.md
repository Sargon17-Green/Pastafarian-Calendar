# SourceLanguageCatalog ережесі

Каталогтың нұсқасы: `1.0.0-stage01`.

Нормативтік ретті тек `canonicalIndex` анықтайды. Қазақша мәтін Unicode ретімен, әліпби ретімен немесе locale collation арқылы сұрыпталмайды және rank/unrank, кэш кілті немесе таңдау семантикасына кірмейді.

Мағынасы бар атаулар қазақша мағынасына аударылды. Жер-су, тарихи және ойдан шығарылған жалқы атаулар дыбыстық тұлғасына жақын кирилл нұсқасымен берілді. Осы Bootstrap үшін детерминді транслитерация қағидасы: бастапқы атаудың дауыссыз қаңқасы мен буын реті сақталады, қазақ кириллицасында бар жақын дыбыс таңдалады, ал мағына ойдан қосылмайды. `Палгураш` және `Қаршумаб` осы қағидамен бекітілді.

Бөлшек түріндегі толық атаулар бір атау ретінде аударылды: `Тоғыздың төрт бөлігі` және `Бестің үш бөлігі`.

Каталог 1-кезең аяқталғаннан кейін спецификацияның нақты өзгерісінсіз өзгертілмеуге тиіс.

`Лагаш`, `Аккад`, `Эриду`, `Урук`, `Ниневия` және `Вавилон` мағына аудармасы емес, тарихи жалқы атаулардың бекітілген қазақ-кирилл тұлғалары ретінде қаралады.
