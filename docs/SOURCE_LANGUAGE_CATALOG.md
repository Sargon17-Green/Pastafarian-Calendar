# SourceLanguageCatalog — 日本語

## 固定規則

この実装の人間向け原文は日本語だけである。名称の意味論的順序は表示文字列ではなく `canonicalIndex` で固定する。

意味を持つ普通名詞と句は意味を日本語へ翻訳する。固有地名は日本語で一般的な表記を優先する。意味を与えられていない造語はカタカナで音写する。

造語の音写では、原形の子音・母音の並びを可能な範囲で標準的な日本語音節へ写し、長音や促音を根拠なく追加しない。本実装では「פַלְגּוּרַשׁ」を「パルグラシュ」、「כַּרְשׁוּמַב」を「カルシュマブ」と固定する。

メソポタミアの既知の地名は日本語で定着した表記を使用する。アッカド、エリドゥ、ウルク、ニネヴェ、バビロンがこれに該当する。

分数句は一つの名称として扱い、「九分の四」「五分の三」とする。

## 不変条件

- カツレツ名は17件。
- 月名は47件。
- `canonicalIndex` は1から連続し、Stage 1 後は変更しない。
- Unicode 順、辞書順、ロケール照合順を意味論的順序に使わない。
- 将来の locale は日本語原文からの表示翻訳だけであり、rank、unrank、cache key、選択結果を変更できない。
