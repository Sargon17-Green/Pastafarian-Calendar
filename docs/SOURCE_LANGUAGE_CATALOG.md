# नेपाली स्रोत-भाषा क्याटलग

क्याटलग संस्करण `ne-NP-source-v1` हो। Stage 1 पछि स्पष्ट specification परिवर्तनबिना यो क्याटलग बदल्न पाइँदैन। क्यानोनिकल क्रम केवल `canonicalIndex` ले निर्धारण गर्छ; नेपाली वर्णक्रम, Unicode क्रम, प्रदर्शन भाषा वा नामको पाठले rank, unrank, छनोट वा semantic cache key बदल्न पाउँदैन।

शाब्दिक अर्थ भएका नाम नेपाली अर्थमा अनुवाद गरिएका छन्। पूर्ण वाक्यांश भएका नाम, जस्तै नौमध्ये चार भाग र पाँचमध्ये तीन भाग, एउटै नामका रूपमा अर्थसहित अनुवाद गरिएका छन्।

स्थाननाम, निजी नाम वा जानाजानी अर्थहीन ध्वनिसमूहलाई अर्थ नथपी देवनागरीमा स्थिर गरिएको छ। यस finite क्याटलगका लागि deterministic लिप्यन्तरण नियम सामान्य अनुमान होइन, तलको frozen mapping नै हो:

- `לגש` → `लगश`
- `פַּלְגּוּרַשׁ` → `पल्गुराश`
- `אכד` → `अक्काद`
- `ארידו` → `एरिडु`
- `כַּרְשׁוּמַב` → `कर्शुमाब`
- `אורוק` → `उरुक`
- `נינוה` → `निनवे`
- `בבל` → `बेबिलोन`

यी आठ रूप यस संस्करणमा अपरिवर्तनीय छन्। कुनै सामान्य Unicode वा locale-आधारित लिप्यन्तरणले तिनलाई फेरि गणना गर्दैन।

भविष्यमा अर्को प्रदर्शन भाषा थपिएमा मार्ग केवल `canonicalIndex -> नेपाली स्रोत string -> locale translation` हुनेछ। उल्टो दिशाबाट string लाई sort, rank, unrank वा semantic निर्णयको आधार बनाउन निषेध छ।
