# Ⲡⲕⲁⲧⲁⲗⲟⲅⲟⲥ ⲛⲧⲙⲉⲧⲁⲥⲡⲉ ⲛⲁⲣⲭⲏ

Ⲧⲁⲥⲡⲉ ⲛⲁⲣⲭⲏ ⲧⲉ ⲧⲙⲉⲧⲣⲉⲙⲛⲕⲏⲙⲉ ⲛⲥⲁϩⲓⲇⲓⲕⲏ. Ⲛϣⲁϫⲉ ⲛϩⲉⲗⲗⲏⲛⲓⲕⲟⲛ ⲙⲛ ⲛϣⲁϫⲉ ⲛⲇⲓⲉⲑⲛⲏⲥ ⲥⲉϣⲟⲟⲡ ϩⲟⲧⲁⲛ ⲟⲩϣⲁϫⲉ ⲛⲁⲣⲭⲁⲓⲟⲛ ⲛϥϣⲟⲟⲡ ⲁⲛ ⲏ ϩⲟⲧⲁⲛ ⲡϣⲁϫⲉ ⲟⲩⲧⲉⲭⲛⲓⲕⲟⲛ ⲡⲉ.

Ⲡⲕⲁⲛⲱⲛ ⲛⲙⲉⲧⲁⲅⲣⲁⲫⲏ ⲡⲉ ⲡⲁⲓ: ⲟⲩⲣⲁⲛ ⲙⲙⲁ ⲉϥⲟⲩⲱⲛϩ ⲉⲃⲟⲗ ϩⲛⲧⲡⲁⲣⲁⲇⲟⲥⲓⲥ ⲛⲕⲏⲙⲉ ⲏ ⲛⲛϩⲉⲗⲗⲏⲛ ⲥⲉϥⲓ ⲙⲡⲉϥⲥϩⲁⲓ ⲉⲧϣⲟⲟⲡ. Ⲉϣⲱⲡⲉ ⲙⲛ ⲟⲩⲥϩⲁⲓ ⲉϥⲧⲁϫⲣⲏⲩ, ⲡⲣⲁⲛ ⲥⲉⲥϩⲁⲓ ⲕⲁⲧⲁ ⲛⲥⲙⲏ, ⲉⲩϩⲁⲣⲉϩ ⲉⲡⲧⲱϣ ⲛⲛⲥⲩⲙⲫⲱⲛⲟⲛ. Ⲛⲣⲁⲛ ⲁϫⲛⲙⲁⲉⲓⲛ ⲛⲥⲉϫⲓ ⲁⲛ ⲛⲟⲩⲙⲁⲉⲓⲛ ⲛⲃⲣⲣⲉ.

Ⲡⲙⲁⲉⲓⲛ ⲛ`canonicalIndex` ⲡⲉ ⲡⲟⲩⲁ ⲙⲙⲁⲧⲉ ⲉⲧϯ ⲙⲡⲧⲱϣ ⲛⲕⲁⲛⲱⲛ. Ⲡⲥϩⲁⲓ ⲛⲧⲙⲉⲧⲣⲉⲙⲛⲕⲏⲙⲉ ⲛϥⲧⲁϣⲉ ⲁⲛ ⲟⲩ `rank`, ⲟⲩ `unrank`, ⲟⲩ `cache_key` ⲏ ⲟⲩⲥⲱⲧⲡ ⲛⲕⲁⲛⲱⲛ.

Ⲡⲉⲓⲕⲁⲧⲁⲗⲟⲅⲟⲥ ⲁϥⲧⲁϫⲣⲟ ϩⲙⲡϣⲟⲣⲡ ⲃⲁⲑⲙⲟⲥ. Ⲙⲡⲣϣⲓⲃⲉ ⲙⲙⲟϥ ϩⲛⲟⲩⲃⲁⲑⲙⲟⲥ ⲉⲧⲛⲏⲩ ⲁϫⲛⲟⲩⲟⲩⲱϩ ⲛⲥⲁϫⲉ ⲛⲕⲁⲛⲱⲛ.
