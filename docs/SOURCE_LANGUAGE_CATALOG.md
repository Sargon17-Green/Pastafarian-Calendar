# כללי שפת המקור

שפת המקור האנושית של קו־המימוש הזה היא עברית בלבד.

1. לכל שם יש `canonicalIndex` קבוע.
2. הסדר הנורמטיבי נקבע רק לפי `canonicalIndex`.
3. אין להשתמש במחרוזת המתורגמת למיון, rank, unrank, בחירה או cache סמנטי.
4. שמות בעלי משמעות נשמרים בעברית כמשמעותם.
5. שמות מקומות ושמות פרטיים נשמרים בכתיב העברי של המקור.
6. צירופי קולות חסרי משמעות נשמרים כצירופי קולות, בלי להמציא להם משמעות.
7. לאחר שלב 1 הקטלוג קפוא ואין לשנותו ללא שינוי מפרט מפורש.
8. locale עתידי, אם יתווסף, יהיה תרגום תצוגתי בלבד של המחרוזות העבריות ולא מקור אמת סמנטי.
