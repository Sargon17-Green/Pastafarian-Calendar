# SourceLanguageCatalog 版本 1

本实现线的唯一人类源语言是简体中文。目录在 第 1 阶段 建立后冻结；后续阶段不得改变名称、顺序或转写规则，除非规范本身明确变更。

## 规范顺序

每个名称都保存固定的 `canonicalIndex`。任何排序、rank、unrank、组合选择、缓存键或规范比较都只使用 `canonicalIndex`。简体中文字符串只在展示层由索引解析得到，永远不反向参与规范计算。

## 翻译与转写规则

1. 有普通词义的名称按词义翻译成自然的简体中文，而不是按源语言读音转写。
2. 已有稳定现代普通话译名的地名和专名采用该译名，例如拉格什、阿卡德、埃里都、乌鲁克、尼尼微和巴比伦。
3. 没有可翻译词义、也没有既定中文译名的声音组合采用固定音节表逐段转写。第 1 阶段 冻结的两个专用映射是：`pal-gu-rash -> 帕尔-古-拉什`，`kar-shu-mab -> 卡尔-舒-姆布`。目录展示时去掉连接号，分别保存为 `帕尔古拉什` 与 `卡尔舒姆布`。相同源音节在本目录中始终使用相同汉字音节，不根据上下文改变。
4. 分数字面短语作为一个完整名称翻译：`九分之四`、`五分之三`。
5. Unicode 顺序、拼音顺序、汉字笔画、locale collation 和大小写规则都不具有规范意义。
6. 将来若增加 locale，其数据流只能是 `canonicalIndex -> 简体中文源字符串 -> locale 翻译`。

## 冻结声明

`SourceLanguageCatalog` 的版本号为 1。第 1 阶段 结束后，17 个肉饼名称和 47 个月份名称的 `canonicalIndex` 与源字符串均视为冻结数据。任何未来展示翻译只能从这些索引和简体中文源字符串派生，不能反向改变规范选择。
