# नेपाली स्रोत-भाषा क्याटलग

क्याटलग संस्करण `ne-NP-source-v1` हो र Stage 1 पछि specification परिवर्तनबिना बदल्न पाइँदैन। क्यानोनिकल क्रम string बाट होइन, `canonicalIndex` बाट मात्र निर्धारण हुन्छ। नेपाली collation, Unicode क्रम वा display locale ले algorithmic क्रम बदल्न पाउँदैन।

शाब्दिक अर्थ भएका नाम नेपाली अर्थमा अनुवाद गरिएका छन्। स्थाननाम, व्यक्तिनाम वा अर्थहीन बनावटी ध्वनिसमूहलाई अर्थ नथपी देवनागरीमा स्थिर रूप दिइएको छ। यस समूहमा लगश, पल्गुराश, अक्काद, एरिडु, कर्शुमाब, उरुक, निनवे र बेबिलोन पर्छन्। यी रूपहरू यस संस्करणमा frozen छन्।

भविष्यको locale ले `canonicalIndex -> नेपाली स्रोत string -> locale translation` मार्ग मात्र प्रयोग गर्नुपर्छ। locale string बाट rank, unrank, sort वा semantic cache key बनाउन निषेध छ।
