# Zmrazený katalog zdrojového jazyka

Katalog obsahuje přesně 17 názvů kotlet a 47 názvů měsíců. Každá položka má neměnný `canonicalIndex`.

Doslovně významové názvy jsou přeloženy do přirozené češtiny. U místních a vlastních jmen se používá běžná česká podoba, je-li ustálená. U dvou umělých zvukových názvů byla pro tuto větev zmrazena deterministická podoba `Palguraš` a `Karšumav`; nejde o pokus jim přisoudit význam.

Kanonické pořadí nikdy nevychází z českého řazení, Unicode, velikosti písmen ani z textu názvu. Veškerá kombinatorika pracuje s indexy. Český řetězec se řeší až v prezentační vrstvě.
