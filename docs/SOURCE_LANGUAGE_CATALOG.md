# स्रोत-भाषा कॅटलॉग

`SourceLanguageCatalog` ची आवृत्ती `1.0.0` आहे आणि Stage 1 पूर्ण झाल्यावर ती गोठवलेली मानली जाते.

## मूलभूत नियम

प्रत्येक नावाला एक स्थिर `canonicalIndex` आहे. नियमाधारित क्रम हा फक्त त्या अनुक्रमांकाने ठरतो. मराठी मजकूर, Unicode क्रम, locale collation, case-folding किंवा वर्णक्रम यांपैकी काहीही निवड, rank, unrank, cache key किंवा combinatorial semantics ठरवत नाही.

अर्थ असलेल्या नावांचे मराठी रूप अर्थानुसार निवडले आहे. पूर्ण वाक्यांश एकच नाव म्हणून भाषांतरित केले आहेत. स्थळनाम, व्यक्तिनाम आणि जाणीवपूर्वक अर्थहीन ध्वनिसमूह यांना अर्थ लावलेला नाही; त्यांचे देवनागरी लिप्यंतर केले आहे.

## निश्चित लिप्यंतर नियम

लिप्यंतर ध्वनी-आधारित आणि निर्धारक आहे. स्रोत उच्चारातील प्रत्येक स्पष्ट व्यंजनासाठी सर्वात जवळचे मराठी देवनागरी व्यंजन वापरले जाते; `sh` प्रकारचा ध्वनी `श`, `kh` प्रकारचा ध्वनी `ख`, `r` `र`, `l` `ल`, `m` `म`, `n` `न` असा स्थिर नकाशा वापरतो. स्पष्ट स्वर `a/e/i/o/u` अनुक्रमे `अ/ए/इ/ओ/उ` या मराठी स्वरमूल्यांशी जुळवले जातात. व्यंजनसमूहाचा क्रम बदलला जात नाही, अर्थपूर्ण मराठी शब्द तयार करण्यासाठी ध्वनी बदलले जात नाहीत, आणि नावाला नवा अर्थ जोडला जात नाही. या Stage 1 मध्ये नोंदवलेली प्रत्यक्ष देवनागरी रूपेच या मार्गासाठी अंतिम स्रोत-रूपे आहेत.

## भविष्यातील locale

भविष्यात locale जोडला तर प्रवाह असा राहील:

```text
canonical semantics -> canonicalIndex -> मराठी स्रोत-नाव -> locale भाषांतर
```

locale मजकूर परत rank, unrank, sort, cache किंवा इतर नियमाधारित निर्णयात जाणार नाही.
