# แค็ตตาล็อกภาษาต้นฉบับ

แค็ตตาล็อกนี้เป็นเวอร์ชัน `1` และถูกตรึงตั้งแต่ระยะที่ 1 การเรียงลำดับเชิงบรรทัดฐานใช้ `canonicalIndex` เท่านั้น ไม่ใช้การเรียงแบบ Unicode การเรียงตามพจนานุกรมภาษาไทย หรือรูปข้อความที่แปลแล้ว

คำที่มีความหมายสามัญแปลตามความหมายเป็นภาษาไทย ชื่อสถานที่ที่มีรูปภาษาไทยใช้อยู่แล้วใช้รูปที่เป็นที่รู้จัก ส่วนชื่อประดิษฐ์ใช้การถอดเสียงตามค่าพยัญชนะและสระที่ปรากฏในรูปต้นฉบับอย่างสม่ำเสมอ ในแค็ตตาล็อกนี้ `פַּלְגּוּרַשׁ` ถอดเป็น `พัลกูรัช` และ `כַּרְשׁוּמַב` ถอดเป็น `คาร์ชูมาฟ` การถอดเสียงไม่มีผลต่อความหมายเชิงบรรทัดฐาน เพราะการเลือกทั้งหมดทำงานด้วยดัชนี

## กฎการถอดเสียงที่ใช้ในเวอร์ชัน 1

ชื่อสถานที่ที่มีรูปภาษาไทยใช้อยู่แล้วใช้รูปภาษาไทยนั้นโดยตรง เช่น ลากาช เอริดู อูรุก นีนะเวห์ อัคคัด และบาบิโลน เพื่อไม่สร้างรูปสะกดใหม่โดยไม่จำเป็น

สำหรับชื่อประดิษฐ์ที่ไม่มีรูปมาตรฐาน อ่านหน่วยเสียงจากพยัญชนะและสระของรูปต้นฉบับก่อน แล้วแปลงหน่วยเสียงด้วยกฎคงที่ของแค็ตตาล็อกนี้: `/p/` ใช้ `พ`, `/k/` ใช้ `ค`, `/g/` ใช้ `ก`, `/l/` ใช้ `ล`, `/r/` ใช้ `ร`, `/m/` ใช้ `ม`, `/ʃ/` ใช้ `ช` และ `/v/` ที่ท้ายพยางค์ใช้ `ฟ`; สระ `/a/` และ `/u/` เขียนตามพยางค์ที่อ่านได้โดยคงลำดับเสียงเดิม ไม่เพิ่มความหมายให้ชื่อ ดังนั้น `/palguraʃ/` เป็น `พัลกูรัช` และ `/karʃumav/` เป็น `คาร์ชูมาฟ` กฎนี้ถูกตรึงพร้อมแค็ตตาล็อกเวอร์ชัน 1

ฟังก์ชัน `cutlets()` และ `months()` สร้าง อาร์เรย์ ใหม่ทุกครั้ง และ `CatalogEntry` เป็น `val` การแก้ อาร์เรย์ ที่ ผู้เรียก ได้รับจึงไม่แก้แค็ตตาล็อกของการเรียกครั้งถัดไป ชุดทดสอบตรวจคุณสมบัตินี้โดยตรง
