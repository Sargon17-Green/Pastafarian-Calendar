# ماخذ زبان کا منجمد کیٹلاگ

## اصول

اس نفاذ میں اردو واحد انسانی ماخذ زبان ہے۔ ہر نام کا مستقل `canonicalIndex` ہے۔ معنوی ترتیب ہمیشہ اسی اشاریے سے طے ہوتی ہے؛ اردو حروف، Unicode ترتیب، لغوی sorting یا locale collation سے کبھی نہیں۔

معنی رکھنے والے نام اردو میں ان کے معنی کے مطابق منتقل کیے گئے ہیں۔ جگہوں، ذاتی ناموں اور بے معنی ایجاد شدہ صوتی ناموں کے لیے صوتی نقل استعمال کی گئی ہے۔ نقل میں قریب ترین مانوس اردو حرف لیا جاتا ہے؛ واضح لمبی مصوتہ کے لیے مناسب طور پر `ا`، `و` یا `ی` استعمال ہوتی ہے؛ اور کسی نام کو نیا معنی نہیں دیا جاتا۔ ایک دفعہ Stage 1 مکمل ہونے کے بعد یہ mapping منجمد ہے۔

مستقبل کا locale صرف اس زنجیر کے بعد آ سکتا ہے:

```text
canonical semantics -> canonicalIndex -> اردو source string -> locale translation
```

الٹی سمت میں کوئی locale string کبھی rank، unrank، selection یا cache semantics نہیں چلاتی۔
