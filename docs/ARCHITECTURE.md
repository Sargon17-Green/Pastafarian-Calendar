# તબક્કો 1નું નિષ્પક્ષ સ્થાપત્ય

આ તબક્કાનો હેતુ ભવિષ્યની જટિલતા પહેલેથી બનાવવાનો નથી. તેથી ઉત્પાદન ભાગમાં માત્ર ચાર નિષ્પક્ષ સ્તરો છે: બોલાવટ-માલિક સંદર્ભ, વિતરણકાર, માન્યતા/ભૂલ સીમા અને અવલોકન ખોળ.

`BaseMonsterContext` દરેક બોલાવટ માટે નવો બને છે. તેમાં હાલ કોઈ કટોરું, ટીપું, દ્વાર, વર્ષ, માળખું અથવા ભવિષ્યના ટાંકા-વિશિષ્ટ સ્થિતિ નથી. આ મર્યાદા ઇરાદાપૂર્વક છે, કારણ કે ઐતિહાસિક સ્થિતિ તે સંબંધિત શોધ અથવા ટાંકા તબક્કે જ ઉમેરવાની છે.

`MetricsShell` અને `LogShell` માત્ર અવલોકન માટે છે. તેઓ નોર્મેટિવ નિર્ણયના ઇનપુટ નથી. `BaseValidationManager` હાલ માત્ર બુટસ્ટ્રેપ અચળતાઓ ચકાસે છે અને કોઈ અર્થનિર્ધારક મૂલ્યને શાંતિથી બદલે નથી.

સ્થિતિ-માલિકીની અલગ તપાસ `docs/STATE_OWNERSHIP_AUDIT.md` માં છે. ખાસ કરીને નામ-સૂચિ હવે અપરિવર્તનીય `Tuple` અચળો તરીકે સંગ્રહિત છે અને પરીક્ષણ સંદર્ભ-ગણક કોઈ વહેંચાયેલ બદલાય શકે એવું પથ્થર કોષ્ટક રાખતો નથી.

પરીક્ષણ સંદર્ભ-ગણક ઉત્પાદનથી અલગ છે. તે `test/normative_scroll.cr` માં છે અને ઉત્પાદન મૉડ્યુલ દ્વારા આયાત થતો નથી. ભવિષ્યના તફાવતી પરીક્ષણમાં અપેક્ષિત મૂલ્ય આ સંદર્ભ-ગણક આપશે અને વાસ્તવિક મૂલ્ય તે જ અમલરેખાના સ્પેગેટી માર્ગમાંથી આવશે.

આ તબક્કામાં પુનઃપ્રાપ્તિ, કૅશ, સુસંગતતા સ્થિતિ, ભૂત-ગણતરી, ઉપનામ, અટકાવ-મૂલ્ય અથવા જૂનો માર્ગ ઉમેરવામાં આવ્યા નથી, કારણ કે એમ કરવાથી ભવિષ્યના તબક્કાનો ઐતિહાસિક ક્રમ તૂટી જાય.
