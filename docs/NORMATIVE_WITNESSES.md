# พยานเชิงบรรทัดฐานของระยะที่ 1

ชุดพยานถูกสร้างจากออราเคิล Pony ของสายงานนี้เท่านั้น ไม่มีค่าคาดหวังจากมימושอื่น

ชุดทดสอบมีพยานที่หาได้จากนิยามโดยตรงสำหรับ `SAVE`, จำนวนวัน, การเรียงสับเปลี่ยน อันดับ 1 และ 720, องค์ประกอบแบบมีขอบเขต, ขอบเขตคัตเล็ต, การสานเดือนขนาดเล็ก, การเลือกแบบสั้นและแบบกว้าง, แถวหินที่ 2, การเปิดอันดับของชื่อไม่ซ้ำ และขอบเขตจำนวนเดือนเมื่อความยาวปีเป็น 252 กับ 5778

โปรแกรม `tools/normative_witnesses` เตรียมพยานระดับสูงเพิ่มเติม โดยพิมพ์ค่าคงที่ ค่า `SAVE`, จำนวนวัน, แถวหินที่ 2, ค่าชามและลำดับชามหลังรอบซอสที่วันฐาน และผลลัพธ์ห้าฟิลด์ของปฏิทินสำหรับวันฐาน วันก่อนหน้า และวันถัดไป

ผลจากโปรแกรมนี้จะถูกบันทึกเป็นค่าคาดหวังของสายงานเมื่อมี `ponyc` และเมื่อการคอมไพล์กับการรันผ่านจริง ก่อนการรันแบบเนทีฟ ห้ามเติมค่าที่คำนวณด้วยภาษาอื่นหรือจากมימושอื่น

ชุดทดสอบยังมีพยานการคูณจำนวนเต็มยาวจากเอกลักษณ์ `(10^n - 1)^2` โดยสร้างทั้งอินพุตและรูปผลลัพธ์ที่คาดไว้ใน Pony การคูณของ `BigInt` สร้างผลคูณย่อยทีละหลักและบวกด้วยเลขฐานสิบแบบแม่นยำ จึงไม่มีตัวสะสมขนาดคงที่ที่สามารถล้นตามความยาวอินพุต
