# 第 2 階段：有限月份交織排名原語契約（2026-10-30）

專案：`PC-BRANCH-PERL-GUOYU`；分支：`Perl+國語`。
使用者已作出實質技術選擇：**先實作獨立且可驗證的交織／排名原語，再進行日期語意實作**。此決定排除了先直接計算五個日期分量的方案；不是形式上的階段核准。

## 範圍與精確語意

本階段只實作小型、具名且完整的月份交織字典序原語，不產生日期答案、不變更曆法五分量核心、不加入歷史缺陷或補丁。
對長度設定 `L=[l_1,...,l_m]`，月份標籤為固定的規範數值索引 `1..m`，不是翻譯名稱。字串 `w` 的長度為 `sum(L)`，每個索引 `j` 恰出現 `l_j` 次，且同時要求：
1. 每個月份的**首次出現**位置，依標籤從 1 到 m 嚴格遞增。
2. 每個月份的**末次出現**位置，同樣依標籤從 1 到 m 嚴格遞增。
由此定義的有效字串按標籤數值的字典序排列，排名**從 1 開始**。例如 `[2,2]` 的合法串只有 `[1,1,2,2]`（排名 1）及 `[1,2,1,2]`（排名 2）。`[1,2,2,1]` 因末次順序而無效。不可用普通多重集合全排列數取代此計數。

## 生產 API

獨立 Perl 模組：`lib/Pastafari/Monster/WeavingPrimitive.pm`
使用 `Exporter` 選擇性匯出以下函式：
- `count_weavings($lengths) -> Math::BigInt`：有效完整序列總數。
- `rank_weaving($lengths,$word) -> Math::BigInt`：合法完整序列的一基字典序排名。
- `unrank_weaving($lengths,$rank) -> ArrayRef[Int]`：從一基排名還原完整序列。

輸入長度為陣列參照，`1 <= m <= 4`，各個 `l_j` 為正十進位整數，`sum(L) <= 12`。輸入序列須恰好包含該個數的有效索引並符合首次及末次規則。排名允許十進位正整數或 `Math::BigInt`，範圍為 `1..count_weavings(L)`；越界／型別錯誤以明確例外拒絕。輸入及傳入的大整數不可遭修改；輸出不共享可變快取。此上限是 Stage2 的**明確能力邊界**，不是日曆全年規模承諾。

## 演算法、獨立性與資源

以剩餘個數向量 `r`、已首次出現的最大標籤 `o`、已完成末次出現的最大標籤 `c` 作為狀態。下一標籤 `j` 只可屬於 `1..min(m,o+1)`、必有剩餘個數；若其本次消耗最後一次，必須滿足 `j=c+1`。對每個允許分支，用帶狀態記憶化的精確整數遞迴計數：
`N(r,o,c)=sum(N(r-e_j,o',c'))`，終端所有剩餘為零時 `N=1`。
排名累積所有字典序較小的候選分支，起始 1；反排名依序扣除分支數。僅使用 `Math::BigInt` 精確整數，無浮點近似。所有記憶化快取都是**單次函式呼叫局部**，不能將診斷或其他輸入結果回饋語意。

生產模組不得載入 `t/lib` 的規範 oracle、不得把 `t/lib` 當作回退答案，不得依賴其他語言實作。此模組尚**未**接入 `calendarDateSpaghetti`；該入口在 Stage2 仍應拒絕未建立的曆法答案。

## 測試及驗收

- Native Perl 5.40，`LC_ALL=C.UTF-8`，`prove -Ilib -It/lib t/47_stage02_weaving_primitive.t`。
- 獨立差分 1：從多重集合全排列獨立窮舉、只在結束後過濾首末次順序；檢查全部有效序列的計數、排名、反排名。至少 100 組完整回合。
- 獨立差分 2：在測試**專用**程式中讀取 `t/lib/Pastafari/NormativeScroll.pm`，核對指定小型設定檔的 `countWeavings/unrankWeaving`；測試必須可執行，不能偷偷略過 oracle 缺席。
- 邊界：空／過長／零月／5 個月、壞標籤、錯誤長度、首末次違反、排名 0、負數、超界、大整數超界及輸入不變性。
- CI：在**同一 SHA** 上通過 Stage2 Native／獨立差分測試與既有專案 verify／names lock 等適用必經閘門；保存 stdout、stderr、退出碼、SHA 和可下載的短期 artifact，並將不可變提交連結寫回追蹤表。Stage1 的 R75 成功不等於 Stage2 的驗收。
- 受控執行：Stage2 Native 運行限制 120 秒、虛擬記憶體上限 384 MiB、無無限枚舉；任何時間／資源超限或 stderr 警告均不能標記為 PASS。
- 只有全部要求達標才可把 `LAST_COMPLETED_STAGE` 改為 2；在此之前 `CURRENT_STAGE=2` 且 `LAST_COMPLETED_STAGE=1`。
