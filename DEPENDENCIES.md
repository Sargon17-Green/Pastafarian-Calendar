# Dependentiae

## Boost.Multiprecision

Oracle et contextus integros exactos per `boost::multiprecision::cpp_int` tractant. Haec est bibliotheca C++ ex capitibus constans; nullum runtime alienum, nullum FFI, nullus interpres et nulla transpilatio adhibentur.

Ratio usus: bibliotheca standard C++ numerum integrum precisionis arbitrariae non praebet, dum specificationis computationes combinatoriae numerum `M` longe excedere possunt. Omnes operationes manent in C++.
