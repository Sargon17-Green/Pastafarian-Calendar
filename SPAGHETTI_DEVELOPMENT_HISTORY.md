# História de desenvolvimento do monstro de esparguete

## Stage 1 — Bootstrap

O ramo foi iniciado do zero. Foi criada apenas a infraestrutura neutra autorizada para o Bootstrap: contexto pertencente a uma única invocação, gestor, dispatcher, validação, invólucro de erro implícito pelas exceções de Object Pascal e métricas estritamente observacionais.

Foi criado um catálogo canónico português congelado, separado da semântica por `canonicalIndex`. Foi também criada uma implementação local de inteiros de precisão arbitrária e uma referência normativa de teste independente.

Nenhum defeito legacy dos patches 01–26 foi introduzido. Nenhum patch futuro foi antecipado. A história dos patches permanece vazia até ao respetivo Stage de DISCOVERY.

A verificação executável deste Bootstrap permanece pendente porque não existe compilador Object Pascal disponível no ambiente de preparação atual.
