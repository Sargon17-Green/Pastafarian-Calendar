# Lokale Laufnachweise

Hier werden ausschließlich Nachweise derselben APL-und-Deutsch-Linie abgelegt. Fremde Implementierungen, deren Ausgaben und deren Hashwerte sind als Beweismittel unzulässig.

`STAGE01_STATIC_AUDIT.md` enthält die abgeschlossene statische Prüfung. Ein nativer Laufnachweis wird erst nach einer tatsächlichen NARS2000-Ausführung ergänzt.
