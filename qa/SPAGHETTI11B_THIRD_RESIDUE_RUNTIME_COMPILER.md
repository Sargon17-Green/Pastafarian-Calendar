now contains the THREE actual worker residue readings, not merely
the original pair:


preserving the exact and substantial QA10 13-byte macro semantics.

`31 33 32`, thirteen generated byte receipts and axis index

after the real third synchronization; generated code subsequently

constructed with stable decimal widths and checked for physical
cell collisions.

worker's real physical arithmetic from `(31+33)/2=32` to
`(31+33)/3=21`. The mutated *standalone QA11A worker fixture*
must still complete and output exactly `31 33 21` — this
distinguishes third-residue corruption from worker suppression.

character must differ from its healthy byte, if that code path
terminates. A mere change of the printed third residue alone is
not accepted as evidence of compilation dependency.
