Etapa 1 — provjera dostupnosti izvornoga Oz/Mozart izvršnoga okruženja

Radno okruženje provjere:
- operacijski sustav: Debian GNU/Linux 13 (trixie)
- arhitektura: amd64 / x86_64
- jezgra: Linux 6.18.35
- glibc: 2.41

Odabrano odgovarajuće izvršno okruženje:
- Mozart 2, izdanje 2.0.1
- službeni Linux paket: mozart2-2.0.1-x86_64-linux.deb
- službeni GitHub release asset: 8527104

Pokušaji dostupnosti i instalacije:
- `command -v ozc` — nije pronađen
- `command -v ozengine` — nije pronađen
- `command -v oz` — nije pronađen
- `apt-cache` ne nudi paket mozart/mozart2 u dostupnim lokalnim indeksima
- osvježavanje APT indeksa nije moguće jer izvršni spremnik nema djelatan vanjski DNS/mrežni pristup
- dohvat službenoga binarnog paketa s GitHub Releasesa odnosno SourceForgea iz izvršnoga spremnika nije uspio zbog istoga mrežnog ograničenja

RUNTIME_INSTALLED=NO
RUNTIME_VERSION=NIJE_DOSTUPNA
NATIVE_COMPILATION_PERFORMED=NO
NATIVE_TEST_EXECUTION_PERFORMED=NO

Zaključak:
Odgovarajući Mozart 2 paket je identificiran, ali ga u ovom izvršnom spremniku nije moguće stvarno preuzeti i instalirati. Ovaj zapis nije dokaz prolaska testova i ne dopušta označavanje etape 1 dovršenom.
