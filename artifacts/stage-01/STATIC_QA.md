# `Stage 1` — статикалык сапат текшерүүсү

Күн: 2026-10-07

## Текшерилген нерселер

- `runtime_contract.b98` ушул линиянын чектелбеген тактыктагы бүтүн сан уячасы талабын жана эки өлчөмдү гана текшерет.
- `2y == -1` Funge-98 стандартынын жалпы талабы эмес; бул ушул линиянын кошумча runtime квалификациялык шарты.
- Funge-98 терс аргументтүү `%` жыйынтыгын implementation-defined калтырат; production код бул семантикага таянбай тургандай кайра жазылды.
- `bootstrap.b98` азыр бир гана `0` операциясын кабыл алган нейтралдуу жөнөткүч кабыгы.
- `day_count.b98` жана `save.b98` `sign magnitude` форматын кабыл алат.
- `sign` `0` же `1` болбосо, же `sign=1,magnitude=0` берилсе, `-1` ката-сентинели кайтарылат.
- `&` командасынын стандарттык unsigned-digit окуу мүнөзүнөн улам тексттик минус белгисине таянуу четке кагылды.
- `save.b98` ичиндеги ар бир `%` үчүн dividend терс эмес жана divisor `M>0`.
- `day_count.b98` `/` жана `%` колдонбойт.
- сыноолордо башка программалоо тилиндеги нормативдик эталон, даяр сыноо маалыматы же күтүлгөн чыгарылыш колдонулган жок.
- `=`, `i`, `o`, `fingerprint`, кокустук жана self-modifying Funge-space жолу колдонулган жок.
- `Stage 2`ге тиешелүү келечектеги оңдоо логикасы кошулган жок.

## Детерминисттик эсептик текшерүү

Production `save.b98` жана `day_count.b98` ошол эле Funge буйруктарынын стек/багыт семантикасын моделдеген өз алдынча эки өлчөмдүү аткаруу модели менен текшерилди.

Ар бир primitive үчүн 6 186 детерминисттик signed-input жуп текшерилди:

- magnitude `0..2047`;
- мыйзамдуу `sign=0`, `sign=1` жана мыйзамсыз `sign=2`;
- `Foundation` тегерегиндеги чек маанилер;
- `M-1`, `M`, `M+1`;
- `2M-1`, `2M`, `2M+1`;
- 50 жана 100 ондук цифралуу чоң magnitudes.

Бардык учур production жыйынтыгы менен нормативдик математикалык формуланын ортосунда дал келди: **0 айырма**.

Кошумча белгилүү чек жыйынтыктары:

- `Foundation-1` → `dayCount=2`;
- `Foundation` → `dayCount=1`;
- `Foundation+1` → `dayCount=3`;
- 0-күн → `dayCount=30111343`;
- `SAVE(-1)=M-1`;
- `SAVE(0)=M`;
- `SAVE(1)=1`;
- `SAVE(M)=M`;
- `SAVE(M+1)=1`;
- `sign=2` → `-1`;
- `1 0` → `-1`;
- `great_number.b98` ичинде так 127 жолу экиге көбөйтүү бар жана сыноо → `1`;
- 2-таш: `378, 1073, 2375, 6195, 10493`;
- `6×42=252`;
- `6×963=5778`.

Бул текшерүү **native Befunge аткаруусунун ордун баспайт**.

## Жергиликтүү аткаруунун абалы

Бул иш чөйрөсүндө ылайыктуу native Befunge-98 интерпретатору менен толук аткаруу далили азырынча жок. Remote компьютерге команданы жөнөтүү аракети Desktop Commander колдонуу чегинен улам команда ишке киргенге чейин токтоду.
