# ปฏิทินพาสตาฟาเรียน — Pony + ภาษาไทย

โครงการนี้เป็นสายการพัฒนาอิสระที่เริ่มจากศูนย์สำหรับการนำอัลกอริทึมเชิงบรรทัดฐานของม้วนกาลเวลามาใช้ด้วยภาษา Pony โดยมีภาษาไทยเป็นภาษาต้นฉบับของข้อความที่มนุษย์เขียนทั้งหมดในโครงการ

ระยะที่ 1 สร้างโครงสร้างพื้นฐานทั่วไป ออราเคิลสำหรับการทดสอบ แค็ตตาล็อกชื่อภาษาไทยแบบตรึง และชุดทดสอบพื้นฐานเท่านั้น ยังไม่มีเส้นทาง legacy หรือแพตช์ในอนาคต

ลำดับชื่อเชิงบรรทัดฐานอาศัย `canonicalIndex` เท่านั้น ข้อความภาษาไทยเป็นชั้นการนำเสนอและไม่มีสิทธิ์เปลี่ยน rank, unrank, cache key หรือผลลัพธ์เชิงความหมาย

การคำนวณเชิงบรรทัดฐานห้ามใช้ floating point และต้องใช้จำนวนเต็มแบบแม่นยำ
