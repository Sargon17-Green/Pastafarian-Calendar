# ಪಾಸ್ಟಾಫೇರಿಯನ್ ಕಾಲಪಟ್ಟಿ — Icon / Unicon + ಕನ್ನಡ

ಈ ಶಾಖೆ ಸ್ವತಂತ್ರವಾಗಿ ಶೂನ್ಯದಿಂದ ಆರಂಭವಾದ ಅನುಷ್ಠಾನ ರೇಖೆ. ಹಂತ 1ರಲ್ಲಿ ಬೇರೆ ಯಾವುದೇ ಅನುಷ್ಠಾನದ ಮೂಲಸಂಕೇತ, ಪರೀಕ್ಷಾ ಫಲಿತಾಂಶ, ಸ್ಥಿರ ಪರೀಕ್ಷಾ ದತ್ತಾಂಶ, ಗೂಢಸಾರ, ಸಂಗ್ರಹಸ್ಮೃತಿ ಅಥವಾ ನಿರೀಕ್ಷಿತ ಫಲಿತಾಂಶ ಬಳಸಲಾಗಿಲ್ಲ.

ಈ ಹಂತದ ಉದ್ದೇಶ ಮೂರು ಭಾಗಗಳಾಗಿದೆ:

1. ಕನ್ನಡವನ್ನು ಏಕೈಕ ಮಾನವ ಮೂಲಭಾಷೆಯಾಗಿ ಸ್ಥಿರಗೊಳಿಸುವುದು ಮತ್ತು 17 ಕಟ್ಲೆಟ್ ಹೆಸರುಗಳು ಹಾಗೂ 47 ತಿಂಗಳ ಹೆಸರುಗಳ `canonicalIndex` ಕ್ರಮವನ್ನು ಹಿಮಗಟ್ಟಿಸುವುದು.
2. ಸಂಲಗ್ನ ನಿಯಮಾತ್ಮಕ ವಿವರಣೆಯಿಂದಲೇ Unicon ನಲ್ಲಿ ಪರೀಕ್ಷಾ ಉದ್ದೇಶದ ಸ್ವಚ್ಛ ನಿಯಮಾತ್ಮಕ ಮಾದರಿಯನ್ನು ನಿರ್ಮಿಸುವುದು.
3. ಮುಂದಿನ ಐತಿಹಾಸಿಕ ದೋಷಗಳು ಅಥವಾ ತಿದ್ದುಪಡಿ ಪದರಗಳನ್ನು ಮುಂಚಿತವಾಗಿ ಸೇರಿಸದೆ, ತಟಸ್ಥ ಮಹಾಕಾಯ ಮೂಲಸೌಕರ್ಯವನ್ನು ಮಾತ್ರ ನಿರ್ಮಿಸುವುದು.

## ಕಡತಗಳು

`src/source_language_catalog.icn` ಕನ್ನಡ ಮೂಲಹೆಸರುಗಳ ಹಿಮಗಟ್ಟಿದ ಪಟ್ಟಿಯನ್ನು ಹೊಂದಿದೆ.

`src/normative_oracle.icn` ಪರೀಕ್ಷೆಗಳಿಗೆ ಮಾತ್ರ ಬಳಸುವ ಸ್ವಚ್ಛ ನಿಯಮಾತ್ಮಕ ಮಾದರಿ. ಕಾರ್ಯನಿರ್ವಹಣಾ ಅಸ್ಥಿಪಂಜರ ಇದನ್ನು ಕರೆಯುವುದಿಲ್ಲ.

`src/monster_bootstrap.icn` ಆಹ್ವಾನ-ಸ್ಥಿತಿ, ಹಂತ ಮಾರ್ಗವಿನ್ಯಾಸ, ಮಾನ್ಯತೆ ಗಡಿ, ದೋಷ ಹೊದಿಕೆ, ಮಾಪಕಗಳು ಮತ್ತು ಸ್ವಾಮ್ಯ ಹೊಂದಿದ ಆಳ-ನಕಲು ವ್ಯವಹಾರಾತ್ಮಕ ಸ್ಥಿತಿಚಿತ್ರಗಳ ತಟಸ್ಥ ಮೂಲಸೌಕರ್ಯವನ್ನು ಒದಗಿಸುತ್ತದೆ.

`test/stage01_tests.icn` ಪೂರ್ಣಾಂಕ ನಿಖರತೆ, ಮೂಲ ನಿಯಮಗಳು, ಸಂಯೋಜನಾ ಗಣಿತ, ರಸತಯಾರಿಕೆಯ ನಿರ್ಣಾಯಕತೆ, ಕನ್ನಡ ಪಟ್ಟಿ, ಕರೆಕ್ರಮ ಪ್ರತ್ಯೇಕತೆ, ಹಿಂತಿರುಗಿಸುವಿಕೆ/ಮರುಪ್ರಯತ್ನ ಮತ್ತು ಸ್ಥಿತಿ ಮಾಲೀಕತ್ವವನ್ನು ಪರೀಕ್ಷಿಸುತ್ತದೆ.

`fixtures/stage01_expected.tsv` ಈ ಅನುಷ್ಠಾನ ರೇಖೆಯಲ್ಲೇ ನಿಯಮಾತ್ಮಕ ವಿವರಣೆಯಿಂದ ನೇರವಾಗಿ ಪಡೆಯಲಾದ ಸಣ್ಣ, ಪರಿಶೀಲಿಸಬಹುದಾದ ನಿರೀಕ್ಷಿತ ಮೌಲ್ಯಗಳನ್ನು ಹೊಂದಿದೆ.

`docs/STATE_OWNERSHIP_AUDIT.md` ಜಾಗತಿಕ ಸ್ಥಿತಿ, ಬದಲಾಗುವ `record`/`table`/`list`/`set` ರಚನೆಗಳು, generator/co-expression ಸ್ಥಿತಿ, ನಿಯಮಾತ್ಮಕ ಸ್ಥಿತಿ, ಪರೀಕ್ಷಾ ಸ್ಥಿತಿ ಮತ್ತು ವಿಫಲತೆ/ಮರುಪ್ರಯತ್ನ ಪ್ರತ್ಯೇಕತೆ ಕುರಿತು ಹಂತ 1ರ ಮಾಲೀಕತ್ವ ಪರಿಶೀಲನೆಯನ್ನು ದಾಖಲಿಸುತ್ತದೆ.
