# Zig + қазақ тілі — 1-кезеңнің Bootstrap жұмыс ағашы

Бұл ағаш нөлден жасалды. Басқа іске асырудың коды, сынақтары, fixtures, күтілетін нәтижелері, журналдары, кэштері немесе hash мәндері қолданылған жоқ.

## Міндетті шекара

Бұл пакет тек 1-кезеңге арналған. 01–26 тарихи ақаулардың ешқайсысы және оларды жөндейтін кейінгі patch жолдары енгізілген жоқ. Қазіргі monster қабаты тек бейтарап `MonsterContext`, dispatcher, validator және metrics қаңқасынан тұрады.

## Ағымдағы техникалық жағдай

`SourceLanguageCatalog` 17 котлет атауы мен 47 ай атауын `canonicalIndex` арқылы бекітеді. Нормативтік oracle-дың күн санағы, SAVE, тастар, жасырын және көрінетін тамшылар, кесе реті, 46 тамшыға дейінгі кесе өңдеуі, 12 кейінгі араластыру, сұрау ағыны және қысқа/кең rank таңдауы жазылды.

Жылдар, қақпалар, котлет құрылымы, bounded ай ұзындықтары, ай тоқымасының DP count/unrank жолы және end-to-end `calendarDate` source деңгейінде материалдандырылды. Бірақ бұл ортада Zig toolchain жоқ болғандықтан, компиляция мен нақты GREEN жүгіру әлі дәлелденген жоқ. Сонымен бірге runtime arbitrary-precision күн осі үшін тұрақты 65535 биттік envelope әлі спецификациядағы шектеусіз талаптың дәл баламасы емес. Сондықтан 1-кезең аяқталды деп белгіленбейді.

## Дәл бүтін сандар

Қазіргі аралық қабат Zig-тің 65535 биттік бүтін сан түрлерін қолданады. Бұл bounded combinatorial кеңістіктер үшін өте кең дәл envelope береді, бірақ спецификация талап ететін шектеусіз runtime arbitrary-precision күн осін әлі толық орындамайды. Келесі жұмыс осы Bootstrap ішінде, 2-кезеңге өтпей тұрып, осы кемшілікті жоюы тиіс.

## Іске қосу

Zig 0.13.0 немесе сәйкес toolchain болғанда:

```text
zig build test
```

Бұл ортада Zig toolchain болмағандықтан, пакет мұнда компиляцияланып іске қосылған жоқ.
