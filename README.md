# ปฏิทินพาสตาฟาเรียน — Pony + ภาษาไทย

โครงการนี้เป็นสายการพัฒนาอิสระที่เริ่มจากศูนย์สำหรับการนำอัลกอริทึมเชิงบรรทัดฐานของม้วนกาลเวลามาใช้ด้วยภาษา Pony โดยมีภาษาไทยเป็นภาษาต้นฉบับของข้อความที่มนุษย์เขียนทั้งหมดในโครงการ

ระยะที่ 1 สร้างโครงสร้างพื้นฐานทั่วไป ออราเคิลสำหรับการทดสอบ แค็ตตาล็อกชื่อภาษาไทยแบบตรึง และชุดทดสอบพื้นฐานเท่านั้น ยังไม่มีเส้นทางข้อบกพร่องเดิมหรือแพตช์ของระยะอนาคต

ลำดับชื่อเชิงบรรทัดฐานอาศัย `canonicalIndex` เท่านั้น ข้อความภาษาไทยเป็นชั้นการนำเสนอและไม่มีสิทธิ์เปลี่ยนอันดับ การเปิดอันดับ กุญแจ แคช หรือผลลัพธ์เชิงความหมาย

การคำนวณเชิงบรรทัดฐานห้ามใช้เลขจุดลอยตัวและต้องใช้จำนวนเต็มแบบแม่นยำ

## การเป็นเจ้าของสถานะ

สถานะที่เปลี่ยนค่าได้ของแต่ละคำขออยู่ใน `MonsterContext ref` ของคำขอนั้นและไม่ถูกเก็บในโครงสร้างส่วนกลาง ขอบเขต ``actor`` ใช้ `MonsterSnapshot val` ซึ่งไม่มี การอ้างอิง ไปยัง อาร์เรย์ หรือ แมป ที่เปลี่ยนค่าได้ รายละเอียดอยู่ใน `docs/STATE_OWNERSHIP.md` และ `docs/REFERENCE_CAPABILITY_AUDIT.md`

`BigInt` เป็น `val` ที่อ่านอย่างเดียวและใช้การคูณฐานสิบซึ่งไม่มีตัวสะสมขนาดคงที่ ส่วน `CatalogEntry` เป็น `val` เช่นกัน ขณะที่สถานะคำขอที่เปลี่ยนค่าได้ยังคงจำกัดอยู่ใน `MonsterContext ref`
