# Պաստաֆարյան օրացույց — D և ժամանակակից հայերեն

Այս ծառը Stage 1-ի զրոյից ստեղծված սկզբնական իրականացումն է։ Այն չի ծագում որևէ այլ ծրագրավորման լեզվով իրականացումից, չի օգտագործում այլ իրականացման թեստեր, fixture-ներ, սպասվող արդյունքներ, hash-եր կամ տարբերակային համեմատություններ։

## Ծրագրավորման լեզուն

Կատարվող ամբողջ հաշվարկային կոդը գրված է միայն D լեզվով։ Թեստային նորմատիվ oracle-ը նույնպես D լեզվով է և օգտագործում է Phobos-ի `std.bigint.BigInt` տեսակը՝ կամայական ճշտության ամբողջ թվերի համար։ Նորմատիվ հաշվարկներում floating point չի օգտագործվում։

## Մարդկային աղբյուրի լեզուն

Այս իրականացման միակ կանոնական մարդկային լեզուն ժամանակակից հայերենն է։ Կոդի նույնացուցիչները, API անունները, ֆայլերի անունները և machine-readable token-ները կարող են մնալ տեխնիկական ձևով, իսկ մարդու համար նախատեսված արձակը գրվում է հայերեն։

`SourceLanguageCatalog`-ը գտնվում է `source/pastafari/catalog.d` ֆայլում։ Այն պարունակում է 17 կոտլետի և 47 ամսվա անունները՝ անփոփոխ `canonicalIndex`-ներով։ Նորմատիվ դասավորությունը միշտ որոշվում է այդ ինդեքսներով, ոչ թե հայերեն տեքստի Unicode դասավորությամբ, այբբենական կարգով կամ locale collation-ով։

## Թարգմանության և տառադարձության կանոն

Բառային նշանակություն ունեցող անունները թարգմանվել են ըստ նշանակության։ Թվային ամբողջական արտահայտությունները պահպանվել են որպես մեկ անուն՝ օրինակ `չորս իններորդ` և `երեք հինգերորդ`։ Պատմական տեղանուններն ու հորինված հնչյունական անունները չեն ստացել նոր նշանակություն. դրանք ամրագրված են փակ, deterministic տառադարձության աղյուսակով՝ `Լագաշ`, `Փալգուրաշ`, `Աքքադ`, `Էրիդու`, `Քարշումաբ`, `Ուրուկ`, `Նինվե`, `Բաբելոն`։ Այս փակ աղյուսակն է տվյալ կատալոգի տառադարձության կանոնը, և Stage 1-ից հետո այն չի փոխվում առանց հստակ specification փոփոխության։

## Stage 1 կառուցվածքը

`source/pastafari/monster_base.d` պարունակում է միայն չեզոք սկզբնական ենթակառուցվածք՝ invocation-ին պատկանող context, հիմնական dispatcher, validator, error wrapper և metrics shell։ Այն դեռ չի պարունակում 26 պատմական legacy սխալներից կամ patch-երից որևէ մեկը։

`tests/normative_oracle.d`-ը մաքուր test-only նորմատիվ reference է, որը վերակառուցվել է ներկառուցված Appendix A-ից։ Այն պարունակում է SAVE-ը, օրվա հաշվիչները, քարերը, թաքնված և տեսանելի կաթիլները, ամանները, հետկաթիլային խառնումները, հարցման հոսքերը, short/wide ընտրությունը, կոմբինատոր ընտանիքների ճշգրիտ count/unrank-ը, դարպասները, տարիները, կոտլետները, ամիսները, weaving-ը և հնգադաշտ վերջնական tuple-ը։ Production skeleton-ը oracle չի կանչում։

`tests/stage01_tests.d`-ը պարունակում է այս գծի նոր fixture-ներն ու invariant ստուգումները։

## Տեղային գործարկում

Համակարգում պետք է հասանելի լինի DMD։ Այնուհետև գործարկվում է միայն՝

```text
./run_stage01.sh
```

Սքրիպտը միայն build/run գործողություններ է կատարում և հաշվարկային տրամաբանություն չի պարունակում։
