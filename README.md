# પાસ્તાફારીયન કૅલેન્ડર — Crystal અને ગુજરાતી

આ કાર્યરેખા સંપૂર્ણપણે શૂન્યથી શરૂ થયેલી સ્વતંત્ર અમલરેખા છે. પ્રથમ તબક્કામાં ઉત્પાદન માર્ગ હજી સંપૂર્ણ કૅલેન્ડર ગણતરી કરતો નથી; અહીં માત્ર નિષ્પક્ષ મૂળ માળખું, પરીક્ષણ માટેનો સ્વતંત્ર નોર્મેટિવ સંદર્ભ-ગણક, ગુજરાતી સ્ત્રોત-ભાષા સૂચિ અને સ્થાનિક પરીક્ષણ માળખું બનાવવામાં આવ્યું છે.

## ભાષા નિયમ

આ અમલમાં માનવ માટે લખાયેલ તમામ ગદ્ય ગુજરાતી છે. અર્થ ધરાવતા નામોનો અર્થ ગુજરાતી ભાષામાં અનુવાદિત કરવામાં આવ્યો છે. સ્થળનામો, વ્યક્તિનામો અને અર્થવિહોણા કલ્પિત ધ્વનિ-નામો માટે સ્થિર ગુજરાતી ધ્વન્યાત્મક લિપ્યંતરણ અપનાવવામાં આવ્યું છે. લિપ્યંતરણમાં મૂળ વ્યંજનક્રમ અને શક્ય સ્વરરૂપ જાળવવામાં આવે છે; તે નામોને નવો અર્થ આપવામાં આવતો નથી.

`SourceLanguageCatalog` માં 17 કટલેટ નામો અને 47 માસ નામો સ્થિર `canonicalIndex` સાથે સંગ્રહિત છે. નોર્મેટિવ ક્રમ હંમેશા આ સૂચકાંક પરથી નક્કી થાય છે. ગુજરાતી લખાણ, `Unicode` ક્રમ, સ્થાનિક ગોઠવણી અથવા ભવિષ્યની સ્થાનિકીકરણ સ્તર કોઈ `rank`, `unrank`, પસંદગી અથવા અર્થનિર્ધારક કૅશ-કી નક્કી કરી શકતી નથી.

## તબક્કો 1નું માળખું

`src/source_language_catalog.cr` ગુજરાતી નામોની સ્થિર સૂચિ ધરાવે છે.

`src/monster_base.cr` માત્ર નિષ્પક્ષ બોલાવટ-સંદર્ભ, વિતરણકાર, માન્યતા-તપાસ, ભૂલ-આવરણ, માપન અને નોંધ-ખોળ ધરાવે છે. કોઈ ઐતિહાસિક જૂની ખામી અથવા ભવિષ્યનો ટાંકો અહીં ઉમેરાયેલ નથી.

`src/pastafarian_calendar.cr` પ્રથમ તબક્કાનું ઉત્પાદન પ્રવેશબિંદુ આપે છે. પૂર્ણ સ્પેગેટી માર્ગ ઇરાદાપૂર્વક હજી ઉપલબ્ધ નથી.

`test/normative_scroll.cr` સમાયેલ નોર્મેટિવ સંદર્ભમાંથી ફરી લખાયેલ સ્વતંત્ર Crystal સંદર્ભ-ગણક છે. ઉત્પાદન કોડ તેને આયાત કે બોલાવતો નથી.

`test/bootstrap_fixtures.cr` પ્રથમ તબક્કા માટેના નાના, સ્વતંત્ર અપેક્ષિત મૂલ્યો અને સરહદી નમૂનાઓ રાખે છે.

`test/stage01_spec.cr` મૂળ ગણિત, સૂચિકાક્રમ, નાની ચોક્કસ સંયોજનાત્મક કુટુંબો, બુટસ્ટ્રેપની નિષ્પક્ષતા અને ઉત્પાદન-સંદર્ભ વિચ્છેદ ચકાસે છે.

`docs/STATE_OWNERSHIP_AUDIT.md` બોલાવટ-માલિકી, બદલાય શકે એવા સંદર્ભોની અલગતા અને સંદર્ભ-ગણકના નમૂના-સ્થિતિનું પરીક્ષણ નોંધે છે.

## સ્થાનિક આદેશો

```text
crystal spec test/stage01_spec.cr
crystal run src/stage01_probe.cr
```

આ તબક્કામાં બીજી પ્રોગ્રામિંગ ભાષા, બીજી અમલરેખા, આંતર-અમલરેખા પરિણામ, નમૂનો, હૅશ અથવા તફાવતી પરીક્ષણ વપરાયેલ નથી.
