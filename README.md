# Befunge + Кыргызча

Бул каталог Пастафари календарын өз алдынча `Befunge-98` менен ишке ашыруучу линиянын `Stage 1 — Bootstrap` ишин камтыйт.

Бул линия башка программалоо тилиндеги ишке ашыруудан көчүрүлбөйт. Алгоритм, сыноо үчүн нормативдик эталон, сыноолор жана кийин түзүлө турган күтүлгөн маанилер ушул линия үчүн `Appendix A` нормативдик сүрөттөмөсүнөн кайра түзүлөт. Башка ишке ашыруунун коду, сыноолору, даяр тест маалыматтары, чыгарылыштары, таблицалары же хэш маанилери бул линияга чындык булагы боло албайт.

## Аткаруу чөйрөсүнүн келишими

Максаттуу диалект — `Befunge-98`.

Funge-98 стандарты уячанын өлчөмүн бир эле туруктуу санга бекитпейт: `2y` аткаруучу чөйрөдөгү бир уяча канча байт экенин билдирет, ал эми `7y` өлчөмдөрдүн санын берет. Бул линиянын так бүтүн сан эсептери машиналык чектен ашкандыктан, **долбоордун кошумча квалификациялык шарты** катары `2y == -1` талап кылынат. Бул Funge-98 стандартынын жалпы талабы эмес; бул жерде `-1` чектелбеген тактыктагы бүтүн сан уячасын колдогон аткаруучу чөйрөнүн келишимдик белгиси.

Funge-98 терс аргумент катышкан `%` жыйынтыгын implementation-defined деп калтырат. Ошондуктан production код мындай семантикага таптакыр таянбайт: `SAVE` ичиндеги бардык `%` операциялары терс эмес санга жана оң модулга гана колдонулат, ал эми азыркы `dayCount` `/` же `%` колдонбойт.

`src/runtime_contract.b98` ошондуктан төмөнкү зарыл шарттарды гана текшерет:

- `2y == -1` — ушул линия талап кылган чектелбеген тактыктагы бүтүн сан уячасы;
- `7y == 2` — Befunge үчүн эки өлчөм.

`fingerprint` кеңейтүүлөрү нормативдик эсепке колдонулбайт. `=`, `i`, `o` аркылуу башка программаны же башка тилдеги календардык кодду чакырууга тыюу салынат.

## Кол коюлган бүтүн санды берүү

Funge-98деги `&` ондук киргизүү командасы цифрага жеткенче башка белгилерди өткөрүп жиберип, андан кийин цифралардын тизмегин окуйт. Ошондуктан тексттик минус белгисине таянууга болбойт. Ар бир тышкы кол коюлган бүтүн сан эки терс эмес бүтүн сан менен берилет:

`sign magnitude`

- `sign=0` — маани `+magnitude`;
- `sign=1` жана `magnitude>0` — маани `-magnitude`;
- нөлдүн жалгыз канондук формасы — `0 0`;
- `1 0`, башка `sign` маанилери жана башка канондук эмес формалар `-1` ката-сентинели менен четке кагылат.

`src/day_count.b98` жана `src/save.b98` ушул форматты окуйт. Мисалы, `-15055671` үчүн киргизүү `1 15055671`.

## Азыркы абал

`Stage 1` башталды, бирок али бүтө элек. Азыр:

- аткаруу чөйрөсүнүн келишимин текшерүүчү программа бар;
- `SAVE` жана `dayCount` үчүн Befunge өзөк операциялары бар;
- Stage 1ге уруксат берилген нейтралдуу base context/dispatcher/validator/error/metrics/logging кабыгы бар;
- азыркы production state ownership текшерилди: shared mutable semantic state жок;
- алар implementation-defined терс `/` же `%` семантикасына таянбайт;
- `Foundation`/`Tablets` якорлорунун Befunge сыноосу бар;
- `M = 2^127 - 1`, `SAVE` четтери, `dayCount` четтери жана канондук `sign/magnitude` шарты үчүн Befunge сыноолору бар;
- 2-тамчы үчүн беш таштын биринчи рекурсиялык кадамын текшерген Befunge сыноосу бар;
- жылдын 252 жана 5778 күндүк чек байланыштарын текшерген Befunge сыноосу бар;
- 17 котлетанын жана 47 айдын кыргызча `SourceLanguageCatalog` иш нускасы түзүлдү;
- каталогдо Carob үчүн акыркы кыргызча лексикалык форма гана ачык бойдон турат;
- толук сыноолук нормативдик эталон, толук календардык өзөк жана ушул линиядан кайра чыгарылган даяр тест маалыматтары али даяр эмес;
- жеткиликтүү иш чөйрөсүндө ылайыктуу Befunge-98 интерпретатору менен native PASS азырынча жок.

`Stage 2` башталган жок жана `Stage 1` толук далилденмейинче башталбайт.
