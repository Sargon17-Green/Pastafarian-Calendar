# Пастафаріанський календар — Chapel + українська

Це незалежна лінія реалізації, створена з нуля за вбудованим нормативним описом. На цьому кроці підготовлено лише етап 1 із 55: початковий каркас, точна арифметика, тестовий нормативний еталон, заморожений каталог назв українською мовою та нейтральна інфраструктура майбутнього «монстра».

## Межі етапу 1

У виробничому маршруті ще немає жодного з 26 історичних дефектів і жодної з відповідних латок. Вони мають з’являтися лише у визначених наступних етапах. Нормативний еталон існує виключно в тестовому просторі й не є резервним шляхом для виробничого коду.

## Мова й точність

Увесь виконуваний код написано Chapel. Для довільно великих цілих значень використовується стандартний тип `bigint` модуля `BigInteger`; обчислення нормативного алгоритму не використовують числа з рухомою комою.

Усі семантичні вибори назв виконуються за незмінним `canonicalIndex`. Український текст ніколи не бере участі у сортуванні, ранжуванні, відкритті рангу, ключах семантичного кешу або виборі результату.

## Запуск локальних тестів

```text
chpl -M src -M test test/stage01_tests.chpl -o stage01_tests
./stage01_tests
```

Очікуваний підсумок після наявності компілятора: усі перевірки етапу 1 проходять і друкується `STAGE_01_RESULT=PASS`.
