# 義大利麵怪物曆法：Perl＋繁體中文（國語）

這是一條從零開始、彼此獨立的實作線。第 1 階段只建立中立的生產骨架、完整的測試專用規範參考、測試框架，以及凍結的來源語言名稱目錄。

## 語言規則

所有可執行程式、測試與規範參考都只使用 Perl。所有人工撰寫的專案說明、註解、診斷文字與提交說明都只使用繁體中文（國語）。識別字、檔名、API 名稱與機器可讀欄位維持技術慣例。

## 名稱語意

名稱的規範順序完全由 `canonicalIndex` 決定。翻譯字串不參與排序、排名、反排名、快取鍵或任何曆法語意。未來若加入其他顯示語系，只能在最終呈現層翻譯本目錄。

## 第 1 階段範圍

本階段沒有加入任何歷史錯誤、相容路徑或 01–26 號修補。生產入口故意尚未提供曆法答案；乾淨的規範參考只存在於測試樹，不能被生產模組載入或當作後援答案。

## 執行測試

```text
prove -Ilib -It/lib -lr t
```

## 第 1 階段：受控資源量測

原生 CI 在完整測試完成後會用獨立子程序進行月份交織小型效能量測，記錄經過時間與 Linux VmHWM/RSS。父程序監看每個案例的時間與 RSS，超限便終止測試子程序。使用者也可在 Linux 手動執行：

`perl -Ilib -It/lib tools/profile_weaving.pl --profile smoke --seconds 15 --rss-kib 262144`

擴充組別（不在一般 CI 裡）：

`perl -Ilib -It/lib tools/profile_weaving.pl --profile extended --seconds 60 --rss-kib 524288`

RSS 取樣不能取代作業系統的硬限制，測試也未驗證最大 47 個月與 5,778 日的資源需求。量測結果不可用作規範日曆答案。
