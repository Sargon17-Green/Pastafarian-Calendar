# पास्टाफेरियन पात्रो — PureScript + नेपाली

यो कार्यान्वयन रेखा शून्यबाट सुरु गरिएको स्वतन्त्र रेखा हो। यसको एकमात्र प्रोग्रामिङ भाषा PureScript हो र मानवले लेखेको क्यानोनिकल भाषा नेपाली हो। अर्को कार्यान्वयनबाट स्रोत, परीक्षण, fixture, अपेक्षित नतिजा, generated table, trace, hash वा checksum लिइएको छैन।

Stage 1 को उद्देश्य तीन भागमा बाँडिएको छ: नेपाली `SourceLanguageCatalog` स्थिर बनाउने, परीक्षण-मात्र क्यानोनिकल oracle को आधार तयार गर्ने, र भविष्यका ऐतिहासिक scar हरू नल्याई तटस्थ monster infrastructure बनाउने।

यस हस्तान्तरणमा execution प्रमाण छैन, किनकि उपलब्ध वातावरणमा `purs` र `spago` भेटिएनन्। त्यसैले यो Stage 1 पूरा भएको घोषणा होइन।
