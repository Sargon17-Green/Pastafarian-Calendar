# Mercury + Монгол хэл — Stage 1 Bootstrap

Энэ мод нь өөр хэрэгжүүлэлтээс хуулбарлаагүй, шинээр эхэлсэн бие даасан шугам юм. Stage 1-д зөвхөн саармаг суурь архитектур, Монгол эх хэлний хөлдөөсөн нэрийн каталог, Mercury дээрх тестийн harness, мөн хавсаргасан норматив дүрмээс шинээр бичсэн тестийн oracle бий.

## Хэлний дүрэм

Ажилладаг бүх код Mercury хэл дээр байна. Хүний унших бүх тайлбар, баримт бичиг, шалгалтын мессеж Монгол хэл дээр байна. Identifier, API нэр, machine code болон файлын нэр нь техникийн хэлбэрээр үлдэж болно.

## Нэрийн семантик

Дотоод сонголт, rank, unrank болон норматив дараалал нь зөвхөн `canonicalIndex` дээр ажиллана. Монгол мөр нь зөвхөн төгсгөлийн presentation үед тайлагдана. Монгол үсгийн эрэмбэ, Unicode дараалал эсвэл locale collation нь норматив утгад оролцохгүй.

## Орчуулга ба галиг

Утгатай нэрийг Монгол утгаар орчуулсан. Газар, хувийн нэр болон утгагүй авианы нийлэмжийг Монгол кириллд тогтвортой галигласан. Тогтсон Монгол хэлбэртэй нэрд тогтсон хэлбэрийг хэрэглэнэ. Тогтсон хэлбэргүй авианы нэрд эхийн гийгүүлэгч, эгшгийн дарааллыг аль болох хадгалж, Монгол кириллд нэг ижил дүрмээр буулгана.

Жишээ:

- Лагаш, Аккад, Эриду, Урук, Ниневе, Вавилон — газар нэрийн тогтсон буюу шууд кирилл хэлбэр.
- Фалгураш, Каршумаб — зохиомол авианы нэрийг утга зохиолгүйгээр тогтвортой галигласан.
- `Есний дөрөв`, `Тавны гурав` — бутархай утгыг нэг бүхэл нэр болгон орчуулсан.

## Бүтээх ба шалгах

Mercury compiler (`mmc`) суусан орчинд төслийн үндсээс:

```text
./RUN_STAGE_01.sh
```

эсвэл:

```text
make test
```

Stage 1-ийн шалгалт амжилттай дуусах хүртэл Stage 2-ыг эхлүүлэхгүй.

## Архитектурын хил

`monster_bootstrap.m` нь зөвхөн ерөнхий context, dispatcher, validation болон observability-ийн саармаг бүрхүүлтэй. 01–26 түүхэн legacy алдаа, patch, compatibility flag, ghost path, latch, alias эсвэл future-stage manager энд байх ёсгүй.

`normative_reference.m` нь зөвхөн test зориулалттай oracle. Production модуль oracle-ийг дуудахгүй.
