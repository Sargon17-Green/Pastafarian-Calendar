# પાસ્તાફારીયન કૅલેન્ડર — Crystal અને ગુજરાતી

આ કાર્યરેખા સંપૂર્ણપણે શૂન્યથી શરૂ થયેલી સ્વતંત્ર અમલરેખા છે. આ પ્રથમ તબક્કામાં ઉત્પાદન માર્ગ હજી સંપૂર્ણ કૅલેન્ડર ગણતરી કરતો નથી; અહીં માત્ર નિષ્પક્ષ મૂળ માળખું, પરીક્ષણ માટેનો સ્વતંત્ર નોર્મેટિવ ઓરેકલ, ગુજરાતી સ્ત્રોત-ભાષા સૂચિ અને સ્થાનિક પરીક્ષણ માળખું બનાવવામાં આવ્યું છે.

## ભાષા નિયમ

આ અમલમાં માનવ માટે લખાયેલ તમામ પ્રોઝ ગુજરાતી છે. અર્થ ધરાવતા નામોનો અર્થ ગુજરાતી ભાષામાં અનુવાદિત કરવામાં આવ્યો છે. સ્થળનામો, વ્યક્તિનામો અને અર્થવિહોણા કલ્પિત ધ્વનિ-નામો માટે સ્થિર ગુજરાતી ધ્વન્યાત્મક લિપ્યંતરણ અપનાવવામાં આવ્યું છે. લિપ્યંતરણમાં મૂળ વ્યંજનક્રમ અને શક્ય સ્વરરૂપ જાળવવામાં આવે છે; તે નામોને નવો અર્થ આપવામાં આવતો નથી.

`SourceLanguageCatalog` માં 17 કટલેટ નામો અને 47 માસ નામો સ્થિર `canonicalIndex` સાથે સંગ્રહિત છે. નોર્મેટિવ ક્રમ હંમેશા આ સૂચકાંક પરથી નક્કી થાય છે. ગુજરાતી લખાણ, Unicode ક્રમ, collation અથવા ભવિષ્યની locale સ્તર કોઈ rank, unrank, પસંદગી અથવા કૅશ-કી નક્કી કરી શકતી નથી.

## તબક્કો 1નું માળખું

`src/source_language_catalog.cr` ગુજરાતી નામોની સ્થિર સૂચિ ધરાવે છે.

`src/monster_base.cr` માત્ર નિષ્પક્ષ context, dispatcher, validation, error wrapper, metrics અને log shell ધરાવે છે. કોઈ ઐતિહાસિક legacy bug અથવા ભવિષ્યનો patch અહીં ઉમેરાયેલ નથી.

`src/pastafarian_calendar.cr` Stage 1 ઉત્પાદન પ્રવેશબિંદુ આપે છે. પૂર્ણ spaghetti માર્ગ ઇરાદાપૂર્વક હજી ઉપલબ્ધ નથી.

`test/normative_scroll.cr` એમ્બેડ કરાયેલા નોર્મેટિવ સંદર્ભમાંથી ફરી લખાયેલ સ્વતંત્ર Crystal oracle છે. ઉત્પાદન કોડ તેને import કે call કરતો નથી.

`test/stage01_spec.cr` મૂળ ગણિત, સૂચિકાક્રમ, નાની exact combinatorial families, bootstrap neutrality અને oracle-વિચ્છેદ ચકાસે છે.

## સ્થાનિક આદેશો

```text
crystal spec test/stage01_spec.cr
crystal run src/stage01_probe.cr
```

આ તબક્કામાં અન્ય પ્રોગ્રામિંગ ભાષા, અન્ય અમલરેખા, cross-implementation output, fixture, hash અથવા differential test વપરાયેલ નથી.
