# تقويم الباستافاريين — خطّ C# بالعربية الكلاسيكية

هذا هو طور التأسيس الأول من خمسة وخمسين طورًا. أُنشئ هذا الخط من شجرة خالية، ولم يُنقل إليه كود ولا اختبار ولا قيمة متوقعة ولا جدول مولَّد من أي تنفيذ آخر.

## ما أُنشئ في هذا الطور

أُنشئت مكتبة الإنتاج الأولية، وهي لا تحتوي بعدُ عيوب الإرث ولا رقع الأطوار اللاحقة. وفيها سياق استدعاء محايد، ومدير أساسي، وموزّع أساسي، ومدير تحقق، وغلاف قياسات لا يغيّر المعنى.

وأُنشئ في مشروع الاختبارات مرجع معياري مستقل مأخوذ من الملحق المعياري المضمَّن في التكليف. يستعمل الحساب الصحيح غير المحدود بواسطة `System.Numerics.BigInteger`، ولا يستعمل عددًا عائمًا في الحساب المعياري.

وأُنشئ كذلك فهرس لغة المصدر المجمَّد: سبعة عشر اسمًا للكُتَيْلات وسبعة وأربعون اسمًا للأشهر. ترتيب الاختيار لا يرجع إلى النص العربي، بل إلى `canonicalIndex` وحده.

## البناء والاختبار

الأوامر المقصودة هي:

```text
dotnet build tests/PastafarianCalendar.Stage01Tests/PastafarianCalendar.Stage01Tests.csproj -c Release
dotnet run --project tests/PastafarianCalendar.Stage01Tests/PastafarianCalendar.Stage01Tests.csproj -c Release
```

لا يحتاج المشروع إلى حزمة خارجية. يعتمد فقط على مكتبات .NET القياسية.

## حدّ هذا الطور

لا يوجد في مسار الإنتاج بعدُ `oldRemainder` ولا غيره من عيوب الإرث الستة والعشرين، ولا توجد رقعة مستقبلية. يبدأ إدخال العيب الأول في طور الاكتشاف الثاني وحده.
