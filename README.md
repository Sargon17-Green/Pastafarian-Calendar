# SQL + தமிழ் — முதல் கட்டத் தொடக்க விதை

இந்த அடைவு SQL மற்றும் தமிழ் செயலாக்க வரியின் **முதல் கட்டத்தை மட்டும்** கொண்டுள்ளது. இது வேறு செயலாக்கத்தை அடிப்படையாகக் கொள்ளாமல் வெற்றிடத்திலிருந்து உருவாக்கப்பட்டது.

செயலாக்க மொழி PostgreSQL SQL. இயக்கப்படும் செயற்கூறுகள் அனைத்தும் `LANGUAGE SQL` என வரையறுக்கப்பட்டுள்ளன. மனித மூல மொழி தமிழ். பெயர் உரை நெறிமுறை கணக்கில் பயன்படுத்தப்படாது; மாற்றமற்ற `canonicalIndex` மட்டுமே தரவரிசை, தரவரிசைத் திறப்பு, தேர்வு மற்றும் நினைவக அடையாளத்திற்கு அதிகாரப்பூர்வமானது.

இந்த கட்டத்தில் முதன்மைச் செயலாக்கம் இன்னும் முழு நாள்காட்டி முடிவை வழங்காது. அது ஒவ்வொரு அழைப்பிற்கும் தனியான சூழல், அடிப்படை வழிமாற்றி, சரிபார்ப்பி, பிழை உறை மற்றும் அளவீடு/பதிவு உறை ஆகிய நடுநிலையான அடுக்குகளை மட்டும் நிறுவுகிறது. வரலாற்றுப் பிழைகள் 01–26 மற்றும் அவற்றிற்கான திருத்தங்கள் எதுவும் முன்கூட்டியே சேர்க்கப்படவில்லை.

இணைப்பு A-இலிருந்து தனியாக மறுவடிவமைக்கப்பட்ட சுத்தமான நெறிமுறை ஒப்புநிலை `pastafari_sql_tamil_test` என்ற சோதனைக்கான தரவுத்தளப் பெயர்வெளியில் மட்டும் உள்ளது. முதன்மை நுழைவு அதை அழைக்காது. முதன்மை கோப்புகளை மட்டும் ஏற்றிய தரவுத்தளத்தில் இந்தச் சோதனைப் பெயர்வெளி உருவாகாததும் தனியாகச் சரிபார்க்கப்படுகிறது.

அனைத்து நெறிமுறை முழு எண் கணக்குகளும் PostgreSQL `numeric` மூலம் துல்லியமாக நடத்தப்படுகின்றன. மிதவை வகைகள், மிதவை தரவரிசை, மடக்கை சார்ந்த கணக்கீடு, `power` சார்ந்த பெரும் முழு எண் கணக்கீடு மற்றும் வாயில் குறியீட்டை `bigint` ஆகச் சுருக்கும் நடைமுறை பயன்படுத்தப்படவில்லை. முழு எண் வகுத்தலுக்கு `div` மற்றும் யூக்ளிடியன் மீதிக்கு துல்லிய முழு எண் செயற்கூறுகள் பயன்படுத்தப்படுகின்றன.

## முக்கியச் சோதனைத் தரவுத்தளத்தில் ஏற்றும் வரிசை

புதிய PostgreSQL தரவுத்தளத்தில் பின்வரும் கோப்புகளை **இந்த வரிசையில்** இயக்க வேண்டும்:

1. `sql/00_schema.sql`
2. `sql/01_source_language_catalog.sql`
3. `sql/02_monster_bootstrap.sql`
4. `sql/test/10_normative_reference.sql`
5. `sql/test/20_stage01_tests.sql`
6. `sql/test/30_stage01_heavy_reference.sql`

ஒவ்வொரு `psql` அழைப்பிலும் `-X -v ON_ERROR_STOP=1` பயன்படுத்த வேண்டும்.

## முதன்மைச் செயலாக்கத் தனிமைப்படுத்தல்

வேறொரு புதிய தரவுத்தளத்தில் பின்வருவன மட்டும் ஏற்றப்பட வேண்டும்:

1. `sql/00_schema.sql`
2. `sql/01_source_language_catalog.sql`
3. `sql/02_monster_bootstrap.sql`
4. `sql/test/40_production_isolation.sql`

இந்தச் சோதனை, சோதனை ஒப்புநிலைப் பெயர்வெளி முதன்மை ஏற்றத்தில் இல்லாததையும், முதன்மைச் செயற்கூறுகள் அதை அழைக்காததையும், அவை SQL மொழியிலேயே இருப்பதையும், மிதவை கணக்குப் பாதை இல்லாததையும் உறுதிப்படுத்துகிறது.

## சரிபார்க்கப்பட்ட நிலை

PostgreSQL 17.6-இல் புதிய தரவுத்தளங்களுடன் முழு இயக்கச் சரிபார்ப்பு செய்யப்பட்டது.

- வழக்கமான முதல் கட்டச் சரிபார்ப்புகள்: **52 / 52 வெற்றி**.
- கனரக நெறிமுறைச் சரிபார்ப்புகள்: **3 / 3 வெற்றி**.
- முதன்மைத் தனிமைப்படுத்தல் சரிபார்ப்புகள்: **4 / 4 வெற்றி**.
- மொத்தம்: **59 / 59 வெற்றி; தோல்விகள் 0**.
- கனரக சோதனை புதிய சரிபார்ப்பு ஓட்டத்தில் சுமார் **87.32 வினாடிகள்** எடுத்தது.

கனரகச் சோதனை வருடம் 5000-ன் உண்மையான 4,244 நாள் / 45 மாத கட்டமைப்பையும், முழு மாத நெய்தலையும், `calendar_date(FOUNDATION, FOUNDATION)` முடிவையும் இயக்குகிறது. எனவே மாத நெய்தல் ஒப்புநிலை சிறிய மாதிரிகளில் மட்டும் சோதிக்கப்பட்டதல்ல.

முழு இயக்கு பதிவு `artifacts/stage-01/POSTGRESQL_EXECUTION_LOG.txt`-இல் உள்ளது.
