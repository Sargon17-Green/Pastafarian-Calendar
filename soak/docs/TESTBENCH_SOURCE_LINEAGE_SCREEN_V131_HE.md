# v131 — סינון חפיפות מקורות לקראת Soak של 10,000 שנים

**תחום:** `qa/soak-lineage-screen-v131`. זהו מבקר קריאה בלבד, ללא הפעלת ממירי תאריכים וללא שינוי ב־`main`.

## מטרת השלב

מפקד v129 אימת את תוכן המקור של **81 רשומות** מתוך 91; v130 איתר ואימת ברמת Git עוד **10 נתיבים מועמדים**, בלי להוכיח שהם נקודות הכניסה לממירים מלאים. לכן קיימות 91 רשומות עם ראיות מקור, אך **אין 91 מנועים עצמאיים מאושרים**.

מבקר v131 מחבר ארבע שכבות ראיה:

1. המפקד ההיסטורי ומפת המאגרים, הענפים והנתיבים.
2. דוח המקור המקורי v129, שנוצר בהרצת CI `44704866938` (completed/success), ובו Git blob SHA, SHA-256, גודל מקור וקומיט ראש הענף שנצפה.
3. דוח ה־triage המקורי v130, שנוצר בהרצת CI `44712740306` (completed/success), ובו עשרה נתיבי מועמד שנמצאו בעצי Git מלאים.
4. ראיות סטטוס CI היסטוריות לשני מקורות הייחוס REF-24 ו־REF-41, הקשורות למנעולי המקור.

הצימוד מתבצע על ידי SHA-256 קאנוני של כל מסמך ראיות; רישום חסר, כפול, לא תואם או כזה המנסה לסמן מנוע כשיר — נדחה.

## שלושת סוגי החפיפה

| סוג | מפתח ההשוואה | מה ניתן להסיק |
|---|---|---|
| עץ מקור משותף | מאגר + ענף + קומיט | הרשומות מתייחסות לאותו snapshot של ענף; **ייתכן** שמדובר במימושים שונים תחת אותו עץ |
| קובץ מקור באותו נתיב | מאגר + קומיט + נתיב | הרשומות מתייחסות לאותו קובץ באותו snapshot |
| תוכן קובץ זהה | SHA-256 של קובץ מקור יחיד | הבתים זהים ברמת ביטחון גיבוב קריפטוגרפי; תלויות ואופן הרצה עלולים להיות שונים |

**שני צדדי ההבחנה חשובים:** קובץ זהה אינו מוכיח שכל האלגוריתם זהה; קבצים שונים אינם מוכיחים אלגוריתמים עצמאיים. בפרט, העתקת קוד, שימוש באותו Oracle, ספריות משותפות, עטיפות ומעברי שפה עשויים ליצור תלות גם בלי SHA זהה.

הדוח `PASTAFARI_SOAK_SOURCE_LINEAGE_SCREEN_V131/1` מחזיר את קבוצות ההתאמה המלאות ואת הדגלים לכל אחת מ־91 הרשומות; אין בו החלטת `DUPLICATE_OF` או `IN_SCOPE` אוטומטית.

## מקוריות הראיות

ה־workflow מאמת דרך GitHub REST את מצבי ההרצות ואת המזהים והגיבובים של שני ארכיוני הראיות:

| שלב | Run | Artifact ID |
|---|---:|---:|
| v129 | `44704866938` | `14615867472` |
| v130 | `44712740306` | `14617838031` |

הארכיונים יורדים בהרשאת `actions: read` ומנותחים **מקומית**. אין שליפת מקור Git חדשה ואין הרצת `F(c,t)` ב־v131. כל פלט חדש נכתב לקובץ חדש בלבד, ב־`xb`, ולא משנה את הראיות המקוריות.

## גבולות ההסמכה

גם כשה־CI עובר, השדות הבאים נשארים תמיד:

- `independent_algorithm_count_certified=0`
- `native_original_full_date_engines_certified=0`
- `official_10000_year_soak_credit=0`
- `native_date_calls=0`
- `soak_dispatch_authorized=false`
- `scientific_soak_10000_pass=false`

לצורך קידום מנוע בהמשך דרושים עדיין: ביקורת נקודת כניסה (F(c,t)) מקורית, מיפוי תלויות וביקורת עצמאות האלגוריתמים, מנעול מקור/בינארי והרצה בתהליך מזוהה, stdout גולמי וקבלה אותנטית, גבולות שנה מאומתים והשוואת כל הימים. השער אינו מאשר את אמיתות הקאנון.

**Issue #29** — אי־הסכמה אמיתית בשדות התאריך בין מנועי מקור — נותר פתוח. `STOP_NEW_NATIVE_SOAK_DISPATCH` נשמר ללא שינוי.

## בדיקות

`soak/process_tests/test_soak_source_lineage_screen_v131.py` מכיל 16 בדיקות סינתטיות: איחוד 91 רשומות, חפיפות זהות נתיב ותוכן, מקור ענף משותף, אי־התאמות SHA, השמטת רשומה, קידום בלתי מורשה, זיוף מקור ה־CI ועוד.
