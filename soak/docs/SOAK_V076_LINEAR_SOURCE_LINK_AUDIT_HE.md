# v076 — תיקון מדרגיות בביקורת קישורי מקור (QA בלבד)

**בסיס נעול:** `0420fd8def1cce607a1761e1d2374a533c188d10`, ענף `qa/soak-readiness-20261114`. 
**ענף תיקון נפרד:** `qa/soak-link-ledger-v076`. אין שינוי ב-`main` ואין שימוש במחשב Windows.

## ממצא

במימוש הקודם `check_original_process_chunk_links` עבר על כל קישורי המקור, וכל `verify_generic_source_link` הריץ מחדש `check_generic_witnesses` על **כל** המקטעים. עבור `N` מקטעים: כ-`N²` סריקות ארכיונים בנוסף לבדיקות הקישור. עבור 1,105 המקטעים האפשריים 1017–2121 מדובר בכ-1,221,025 ביקורות ארכיון במקום בדיקה ליניארית.

## תיקון

1. `check_original_process_chunk_links` מריץ פעם אחת את ביקורת כלל ה-witnesses ולאחריה בודק כל קישור בנפרד.
2. `verify_generic_source_link` מאפשר דילוג על *סריקה כוללת* רק כשהקורא מצהיר שכבר ביצע אותה; עדיין בודק את תוכן ה-ZIP הנעול, את ה-SHA של כל קישור ואת הנתונים וה-sidecars שלו.
3. `verify_and_recover` קורא תחילה לסריקה הכוללת הקיימת ואז מעביר את סימן האימות לביקורת הקישורים. כך נחסכת גם סריקה כפולה.
4. מסלול האימות העצמאי (ללא סימן) ממשיך לסרוק את ה-witnesses ולדחות השחתה. שגיאת סריקה כוללת עוצרת את הביקורת לפני קבלת קישור כלשהו.

**סיבוכיות ייחוס:** ביקורת כללית אחת ועוד ביקורת קישור אחת לכל מקטע, `O(N)` במספר הארכיונים, בלי לשנות את האלגוריתמים המקוריים או את קלט `F(c,t)`.
