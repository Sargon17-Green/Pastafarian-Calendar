## 3. שער v047 — הצלבה בלתי־משנה של ראיות מקור

נוסף `soak/runner/supervised_original_pair_artifact_v047.py`.

הוא בודק ארכיון ZIP שנעול לגיבוב `2bcf3c15...`, תוך דחיית ערכים כפולים ושמות ZIP חשודים, גודל מופרז, גיבובי קבצים שהשתנו, רשומות JSON כפולות, נתיב מקור שגוי, קוד יציאה לא־אפס, קבלה לא־קאנונית, שינוי `c` או `t`, שינוי מזהי המנוע או גרסאות המקור, ושינוי נתוני תאריך גולמיים.

לגבי Python הוא מצליב את `native-raw.jsonl` עם `native-normalized.jsonl` ואת `source_raw_sha256` עם שורת המקור הגולמית **כולל LF**, ומשווה לשמות `Akrep` ו־`Kuyu` מתוך המקור. הוא מאמת את פקודת ההפעלה המוצהרת ואת קבלת הטרנספורט, תוך **שימור `boundary_evidence_sha256=null` בקבלה המקורית** ודרישה ל־SHA הגבולות בקבלת ה־Supervisor.

לגבי Kotlin הוא בודק את SHA-256 של ה־JAR המקורי, גיבובי קובצי הייצור כפי שנרשמו, קובץ קלט `c\tt`, פקודת JVM ואת שבעת השדות ב־`os-stdout.tsv` — פלט הנתונים הגולמי של Kotlin. אז הוא משווה **חמישה שדות תאריך**, בלי להעניק קרדיט לשנה מלאה.

**הגבלה:** זהו אימות פנימי של חבילה שכבר הופקה על ידי GitHub Actions; חותמת גיבוב שצורפה לחבילה אינה הוכחה עצמאית של זהות התהליך או של עצמאות האלגוריתם.
