## חוזה מקור לכל רשומה

\`soak/runner/soak_source_census_v129.py\` פונה ל־GitHub REST
לצורך **קריאה בלבד**:

1. מאמת שכל 91 מזהי הרשומות מתאימים בין קובצי המפקד והמקור,
   ללא כפילות, השמטה או נתיב בלתי בטוח.
2. מונה את הענפים הנגישים בכל מאגר ומקבל \`head SHA\` לכל ענף. 
   **גישה חסרה למאגר אינה מוצגת כאילו הענף חסר או פגום**.
3. מבקש את קובץ המקור לפי **קומיט מלא**, ולא לפי כינוי ענף מתחלף.
   משווה גודל, Git blob SHA-1, ומשמר SHA-256 של הבתים שהוחזרו.
4. נמנע מהורדה כפולה של אותו שילוב מאגר/קומיט/נתיב.
5. עבור \`REF-41\` ו־\`REF-24\` בלבד, משווה גם את כל הקבצים
   המצויים במנעול המקור \`pilot_two_engine_source_locks_v001.json\`
   אל המידע המגיע מקומיטים קבועים. נתיב התלות של JavaScript
   נבדק בנוסף לקובץ הכניסה.
6. מקפיא דוח JSON של 91 רשומות, מספרי הצלחה, כשלי גישה, SHA של
   כל קובץ המקור וכל מסמכי המפקד, וסטטוס המנעולים הנעולים.
   הדוח נשמר ב־artifact של הרצת GitHub Actions; נתונים דינמיים
   **אינם** נכתבים אוטומטית אל \`main\` או לתוכנית ההרצה.

## משמעות הסיווגים

- \`SOURCE_BYTES_VERIFIED_AT_HEAD\`: הקובץ התקבל מקומיט ראש ענף
  נצפה ועבר בדיקת SHA-1 Git וגודל. אינו מאשר הרצה.
- \`FROZEN_SOURCES_SHA_LOCK_PASS\`: כל קובצי המקור הנעולים,
  לרבות תלויות, תואמים SHA-256, Git blob וגודל מהיסטוריית הקומיט.
- \`SOURCE_PATH_NOT_DECLARED\`: אין נתיב למימוש; נדרש מיפוי.
- \`REPOSITORY_UNAVAILABLE_OR_NO_ACCESS\`: אין גישה מספקת
  לבדוק את המאגר; אין לקבוע שהקוד או הענף חסרים.
- \`BRANCH_ABSENT_FROM_ACCESSIBLE_LIST\`: לא נמצא במניין הענפים
  הנגיש שהוחזר; נדרש המשך בירור.
- \`FROZEN_SOURCE_LOCK_MISMATCH\`: חוסר התאמה פיזית בין
  מקור הנעול לבין תגי ההתחייבות, המחייב עצירה.
- \`NO_FROZEN_SOURCE_LOCK\`: מצב ברירת המחדל לכל רשומה
  מלבד שני מקורות v016; אין להמציא מנעול חדש.

## מה לא מאומת

נוכחות הקוד וה־SHA **אינן** הוכחת הצלחה של \`compile\`, \`link\`,
הרצת התוכנית, מקוריות קוד מערכת ההפעלה, התאמת stdout לתהליך,
בדיקות שנים מלאות או עצמאות אלגוריתמית. מקור בעל שני ענפי עטיפה
אינו מנוע נוסף ללא ביקורת lineage עצמאית.

כל 91 הרשומות מחזיקות:
\`native_build_success_verified_by_census=false\`,
\`native_full_date_execution_verified_by_census=false\`,
\`independent_algorithm_certified_by_census=false\`,
\`eligible_for_soak=false\`.

המודול אינו משנה את רשומות \`v127\` ואינו יוצר \`IN_SCOPE\`
אוטומטי. המסע המדעי נשאר **0/10,000**.
חסימת Issue #29 ממשיכה להתקיים, ללא עקיפת CI מותרת.
