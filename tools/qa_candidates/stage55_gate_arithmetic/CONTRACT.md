# Stage55 gate arithmetic profiling contract (QA only)

## Purpose

The memo-cache pilot showed six public five-field matches and four outer-route repeat matches, but its estimated full session was 10,632.238244 s, above the 10,000 s limit. A cache hit also bypasses the inner defect/patch compatibility-route chain. This experiment profiles the exact arithmetic while keeping that entire chain physically active on every measured call.

## Pinned inputs

- Production baseline commit: \`341927541dccc940bfc5e2b4073c21c647261278\`
- Original \`BigInt.m\` Git blob: \`86581532df7492a236283c5ee9410ca281e2e6f5\`
- Original \`GateQuestionEngine.m\` Git blob: \`4b774c90f9a2fcdccaa2baac3ef80b0e8e99489e\`
- MATLAB release: R2026a
- Fixed foundation: -15055671
- Target offsets: -12..-1 and +1..+12 (24 distinct target days)
- Measured invocations: two full passes, 48 calls to \`GateQuestionEngine.gapForQuestionDay\`

## Contract

### Inputs

1. The two pinned source files above, plus all other source files from the exact baseline commit.
2. A deterministic JSON vector set generated by Python's built-in arbitrary-precision integers.
3. Direct target-day calls to the original \`GateQuestionEngine\`; no memoization or cache overlay is installed.

### Outputs

1. For every arithmetic vector: exact decimal quotient and remainder.
2. For each of 48 direct gate-engine invocations: target day, exact gap, and elapsed seconds.
3. MATLAB profiler call counts and time for all nine inner compatibility-route classes:
   - WorkCounts
   - StoneTable
   - Hidden
   - VisibleDrop
   - GrindTable
   - BowlPour
   - BowlStir
   - OrderAt46
   - GeneralSelection
4. Bounded watchdog evidence for MATLAB process-tree RSS and elapsed time.

### Independent oracle

For each vector with integer dividend \`a\` and positive divisor \`b\`, Python computes:

\`q, r = divmod(a, b)\`

The verifier requires \`a = q*b + r\` and \`0 <= r < b\`, then compares MATLAB's decimal strings byte-for-byte with the Python values. Vectors cover the fixed Mersenne divisor \`2^127-1\`, one-limb divisors, multi-limb divisors, negative dividends, exact multiples, and boundary values.

### Required invariants

- The original \`GateQuestionEngine.m\` blob is unchanged.
- The original \`BigInt.m\` blob is unchanged in this baseline-only profile.
- Each of the nine compatibility-route classes is called exactly 48 times.
- No cache is introduced; every call executes the original inner defect/patch chain.
- The profile is diagnostic only. It does not accept Stage55, change production, or authorize adoption.

## Resource bounds

- MATLAB process-tree RSS ceiling: 3 GiB.
- Watchdog wall-time ceiling: 10,000 s.
- CI job timeout: 30 minutes.
- One MATLAB thread.

## Decision rule

Use the measured MATLAB profiler output to select the next exact-arithmetic optimization. Any subsequent candidate must preserve all nine physical route calls per invocation, pass the same independent Python oracle, and be compared against this pinned baseline. This profile alone is not a performance or Stage55 acceptance gate.
